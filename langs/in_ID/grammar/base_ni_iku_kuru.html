Tujuan Pergerakan: ～に行く / ～に来る

Ungkapan ini digunakan untuk mengatakan bahwa Anda "pergi" atau "datang" `untuk` melakukan tindakan tertentu. Ini menghubungkan suatu tujuan dengan kata kerja gerakan.

1. Struktur Kalimat

Lampirkan partikel `に` ke `Batang Kata Kerja` (bagian sebelum `~ます`), diikuti dengan kata kerja gerak seperti `行く` (pergi), `来る` (datang), atau `帰る` (kembali).

`[Batang Kata Kerja] + に + [Kata Kerja Gerakan]`

  • スーパーへ買かいものに`行いきます`。
    (Saya pergi ke supermarket untuk berbelanja.)
  • 図書館としょかんへ勉強べんきょうしに`行いきました`。
    (Saya pergi ke perpustakaan untuk belajar.)
  • うちに遊あそびに`来こてください`。
    (Silakan datang ke rumah saya untuk bermain/nongkrong.)

2. Menggunakan dengan Kata Benda

Jika tindakan tersebut sudah berupa kata benda (seperti "belanja" atau "belajar"), Anda dapat menambahkan `に` langsung ke tindakan tersebut tanpa `する`.

  • デパートへ買かいもの`に`行いきます。
    (Saya pergi berbelanja.)

3. Visualizing the Structure

`に` bertindak sebagai penanda target niat Anda. Anda sedang bergerak `menuju` tindakan tersebut.
