Setelah Melakukan: ～あとで

Untuk mengatakan "setelah melakukan sesuatu" atau "setelah kejadian tertentu", bahasa Jepang menggunakan `～あとで`. Ini kebalikan dari `～前まえに`.

1. Menggunakan dengan Kata Kerja

Gunakan `Past Tense (Ta-form)` dari kata kerja. Ini karena tindakan tersebut harus diselesaikan sebelum tindakan berikutnya dimulai.

`[kata kerjaた形たけい] + あとで`

  • 仕事しごとが終おわった`あとで`、飲のみに行いきます。
    (Setelah pekerjaan selesai, saya akan pergi minum.)
  • 映画えいがを見みた`あとで`、カフェに行いきました。
    (Setelah menonton film, saya pergi ke kafe.)

2. Menggunakan dengan Kata Benda

Saat menggunakan kata benda (suatu peristiwa), hubungkan menggunakan partikel `の`.

`[Kata benda] + の + あとで`

  • 授業じゅぎょう`のあとで`、先生せんせいに質問しつもんしました。
    (Setelah kelas selesai, saya mengajukan pertanyaan kepada guru.)
  • テスト`のあとで`、アイスクリームを食たべました。
    (Setelah tes, saya makan es krim.)

3. Perbandingan: ～てから

Struktur serupa adalah `～てから`. Meskipun `あとで` hanya menandai urutan kejadian, `てから` menekankan bahwa tindakan pertama merupakan prasyarat untuk tindakan kedua.

  • 手てを洗あらってから、食たべます。
    (Setelah mencuci [dan karena saya mencuci] tangan saya, saya makan.)
