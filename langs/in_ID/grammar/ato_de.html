Setelah Melakukan: ～あとで

Untuk mengatakan "setelah melakukan sesuatu" atau "setelah peristiwa tertentu," penggunaan bahasa Jepang～あとで. Ini adalah kebalikan dari～前まえに.

1. Menggunakan dengan Kata Kerja

GunakanBentuk lampau (bentuk Ta)dari kata kerja. Ini karena tindakan tersebut harus diselesaikan sebelum tindakan berikutnya dimulai.

[Kata kerjaた形たけい] + あとで

  • 仕事しごとが終おわったあとで、飲のみに行いきます。
    (Setelah pekerjaan selesai, saya akan pergi minum.)
  • 映画えいがを見みたあとで、カフェに行いきました。
    (Setelah menonton film, saya pergi ke kafe.)

2. Menggunakan dengan Kata Benda

Saat menggunakan kata benda (suatu peristiwa), hubungkan menggunakan partikelの.

[Kata benda] + の + あとで

  • 授業じゅぎょうのあとで、先生せんせいに質問しつもんしました。
    (Setelah kelas selesai, saya mengajukan pertanyaan kepada guru.)
  • テストのあとで、アイスクリームを食たべました。
    (Setelah tes, saya makan es krim.)

3. Perbandingan: ～てから

Struktur serupa adalah～てから. Ketikaあとでcukup menandai urutan kejadian,てからmenekankan bahwa tindakan pertama merupakan prasyarat untuk tindakan kedua.

  • 手てを洗あらってから、食たべます。
    (Setelah mencuci [dan karena saya mencuci] tangan saya, saya makan.)
