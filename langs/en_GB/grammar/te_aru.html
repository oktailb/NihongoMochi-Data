Resulting State: ～てある

The expression ～てある is used to describe a state that exists as a result of an intentional action performed by someone. It often implies that someone did something for a specific purpose, and the result is still visible.

1. Sentence Structure

Attach ある to the Te-form of a transitive verb (a verb that takes an object, like "to open" or "to write").

[Object] が + [Verb て形てけい] + ある

  • 窓まどが開あけてあります。
    (The window has been opened [and is still open].)
  • カレンダーに予定よていが書かいてあります。
    (The schedule has been written on the calendar.)

2. ～てある vs ～ている

While both describe a state, the nuance is different:

  • ～ている: Simply describes a state or ongoing action (e.g., "The window is open"). It doesn't focus on who did it or why.
  • ～てある: Focuses on the fact that someone purposely did it (e.g., "Someone opened the window for a reason").

3. Usage with Preparation

It is often used when preparations have been completed.

  • 料理りょうりはもう作つくってあります。
    (The food has already been prepared [for the guests].)

4. Quick Tip

If you see the particle が with a transitive verb in the te-form + aru, it's almost certainly this "resulting state" grammar!
