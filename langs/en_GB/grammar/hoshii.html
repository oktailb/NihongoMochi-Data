Wanting Something: ～ほしい

The adjective `ほしい` (written as `欲しい`) is used to express that you want an object, or that you want someone else to do something for you.

1. Wanting an Object

Use the particle `が` to mark the object you want.

`[Object] が ほしいです`

  • 新あたらしい車くるま`がほしい`です。
    (I want a new car.)
  • プレゼントは何`がほしい`ですか。
    (What do you want for a present?)

2. Wanting Someone to do Something

Use the `Te-form` of a verb followed by `ほしい`.

`[Verb て形てけい] + ほしい`

  • 一緒いっしょに来き`てほしい`です。
    (I want you to come with me.)
  • 日本語にほんごを教おしえ`てほしい`んですが。
    (I'd like you to teach me Japanese [polite request].)

3. Conjugation

`ほしい` is an `I-adjective`.

  • `Negative:` 欲ほしくない (Don't want)
  • `Past:` 欲ほしかった (Wanted)

4. Warning: Self-Centered

Just like `～たい`, `ほしい` is generally used only for the speaker's own desires. To describe what someone else wants, use `～ほしがっている` (see `がる` form).
