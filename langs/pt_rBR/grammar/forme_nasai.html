Dando Comandos: ～なさい

O～なさいo formulário é usado para dar um comando ou instrução firme. Embora seja gramaticalmente educado (derivado do título honoríficonasaru), carrega um forte tom de autoridade. Geralmente é usado por pais para filhos, professores para alunos ou em instruções escritas para exames.

1. Como conjugar

Anexarなさいdiretamente para oHaste verbal(a parte anterior~masu).

[Raiz verbal] + なさい

  • 食たべます →食たべ + なさい =食たべなさい(Comer!)
  • 行いきます →行いき + なさい =行いきなさい(Ir!)
  • します → し + なさい =しなさい(Faça isso!)

2. Exemplos principais

  • 「もう遅おそいから、早はやく寝ねなさい。」
    ("Já é tarde, entãoVá dormirrapidamente.")
  • 「テレビを消けして、宿題しゅくだいをしなさい。」
    ("Desligue a TV efazersua lição de casa.")
  • 「つぎの質問しつもんに答こたえなさい。」
    ("Respondera seguinte pergunta.")

3. Nuance: Quando NÃO usar

Porque～なさいimplica uma hierarquia clara onde o falante tem autoridade sobre o ouvinte, você devenuncause-o para um superior (chefe, professor) ou um estranho. Nesses casos, use～てくださいpara solicitações.

4. Dica rápida: ～なさい vs ～ろ (imperativo)

  • ～なさい:Firme e autoritário, mas usado de forma “corretiva” ou educativa (pais, professores).
  • ～ろ (forma imperativa):Muito áspero, agressivo ou usado em emergências. Parece muito mais duro do que~nasai.
