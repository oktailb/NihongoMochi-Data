Contanto que / Dentro dos limites: ～かぎり

A expressão～かぎり(escrito como～限り) é usado para definir uma condição ou um limite. Isso se traduz como "enquanto...", "enquanto um estado continuar..." ou "na medida de...".

1. Contanto que (Condição)

Use isto para expressar que um determinado resultado continuará enquanto a situação atual permanecer inalterada.

  • 体からだが丈夫じょうぶなかぎり、働はたらきつづけたい。
    (Desde quemeu corpo está saudável, quero continuar trabalhando.)
  • この契約けいやくを守まもるかぎり、問題もんだいはありません。
    (Desde quevocê segue este contrato, não há problemas.)

2. Dentro dos limites de (Extensão)

Use isso para enfatizar que você está fazendo todo o possível ao seu alcance ou conhecimento.

  • 力ちからのかぎり、頑張がんばります。
    (farei o meu melhorna medida demeu poder.)
  • 私の知しっているかぎりでは、かれは犯人はんにんではありません。
    (Tão longe quantoEu sei, ele não é o criminoso.)
