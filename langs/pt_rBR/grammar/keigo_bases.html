As Bases de Keigo (敬語けいご)

Keigoé o sistema honorífico em japonês. É usado para mostrar respeito, distância social e educação. Na sociedade japonesa, a escolha do nível certo de Keigo depende de com quem você está falando e de sua posição social relativa.

1. Os três tipos de Keigo

Keigo é dividido em três categorias principais:

Categoria Nome Japonês Uso
Educado 丁寧語ていねいご Polidez geral para com qualquer pessoa (usadesu/masu).
Honorífico 尊敬語そんけいご Para elevar as ações de umsuperior(chefe, professor, cliente).
Humilde 謙譲語けんじょうご Para abaixarseu próprioações para mostrar respeito a um superior.

2. Formulário Respeitoso (尊敬語そんけいご) Padrões

Isso é usado quando se falasobrealguém que você respeita. Um padrão comum é:

お + [radical verbal] + になります

  • 先生せんせいはもうお帰かえりになりました。
    (A professora já voltou para casa.)
  • チケットをお持もちになっていますか。
    (Você [homenageado] está com seu ingresso?)

3. Forma humilde (謙譲語けんじょうご) Padrões

Isso é usado quando se fala sobre suas próprias ações dirigidas a um superior. Um padrão comum é:

お + [radical verbal] + します

  • お荷物にもつをお持もちします。
    (Vou carregar suas malas [humildemente].)
  • 明日あした、お電話でんわします。
    (Eu te ligo amanhã.)

4. Quando usar Keigo?

Pense nisso como um sistema "In-group/Out-group" (Uchi-Soto). Você usa Keigo para pessoas fora do seu círculo (clientes, estranhos) ou pessoas acima de você (seu chefe). Você faznãouse-o para você ou para seus familiares ao conversar com outras pessoas.
