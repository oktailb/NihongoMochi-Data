A Forma Volitiva / Conjectural (意向形いこうけい)

OForma Volitivaé o equivalente casual de～ましょう. É usado para dizer "Vamos fazer [alguma coisa]" ou para expressar a intenção ou resolução de fazer algo.

1. Como conjugar

Grupo 1: Verbos U (Godan)

Mude a final"você"som para o correspondente"ó"som e, em seguida, adicione um longoう.

  • 行いく →行いこう(Vamos)
  • 買かう→買かおう(Vamos comprar)
  • 話はなす→話はなそう(Vamos conversar)
  • 待まつ→待まとう(Vamos esperar)

Grupo 2: Ru-Verbos (Ichidan)

Removerるe adicioneよう.

  • 食たべる →食たべよう(Vamos comer)
  • 見みる→見みよう(Vamos assistir)
  • 寝ねる→寝ねよう(Vamos dormir)

Grupo 3: Verbos Irregulares

  • する →しよう
  • 来くる→来こよう(pronunciadoko-você)

2. Uso Comum

  1. Convite casual (vamos...)
    「どこかへ行いこう！」
    (Vamos para algum lugar!)
  2. Expressando Intenção (～ようと思っている)
    来年らいねん、日本にほんに行いこうと思おもっています。
    (Estou pensando em ir para o Japão no próximo ano.)

3. A Conjectural Polida (～でしょう)

Embora a forma volitiva seja para "Vamos", a palavraでしょう(educado) ouだろう(casual) é usado para "Provavelmente".

  • 明日あしたは雨あめが降ふるでしょう。
    (Provavelmente choverá amanhã.)
