Conjugação Condicional (仮定形かていけい)

O～ばform é usado para criar sentenças condicionais (se...). Dominar sua formação é essencial para padrões gramaticais avançados como "quanto mais... mais...".

1. Verbos

Grupo 1: Verbos U (Godan)

Mude a final"você"som para o correspondente"e"soar e adicionarば.

  • 行いく → 行いけば
  • 話はなす → 話はなせば
  • 飲のむ → 飲のめば

Grupo 2: Ru-Verbos (Ichidan)

Substitua o finalるcomれば.

  • 食たべる → 食たべれば
  • 見みる → 見れば

Grupo 3: Verbos Irregulares

  • する →すれば
  • 来くる→来くれば(pronunciadokureba)

2. Adjetivos

I-Adjetivos

Substitua o final～いcom～ければ.

  • 暑あつい → 暑あつければ
  • 安やすい → 安やすければ
  • いい(Bom) →よければ(Irregular)

Na-Adjetivos e Substantivos

Adicionarなら (ば)ouであれば.

  • 暇ひま → 暇ひまならば
  • 学生がくせい → 学生がくせいならば

3. Verbos Negativos

Para dizer "se [um] não...", substitua o～いdoForma Naicom～ければ.

  • 行いかない →行いかなければ(Se eu não for)
  • 食たべない →食たべなければ(Se eu não comer)
