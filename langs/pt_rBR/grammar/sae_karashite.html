Até o menor detalhe: ～さえ / ～からして

Quando queremos mostrar que uma situação é tão intensa que até o exemplo mais básico ou inesperado é verdadeiro, usamos～さえou～からして. É como dizer "Mesmo X é verdade, então obviamente o resto também é!"

1. Estrutura da frase

  • Substantivo+ さえ
  • Substantivo+ からして

2. Exemplos extremos

  • 子供こどもさえ知っている。
    (Até uma criança sabe disso.)
  • 彼は自分の名前さえ書けない。
    (Ele nem consegue escrever seu próprio nome.)
  • この料理りょうりは、においからしておいしそうだ。
    (A julgar pelo cheiro, este prato parece delicioso.)

3. Nota do Sensei

～さえé usado para "par" geral.～からしてé especificamente para dizer "a julgar até mesmo por X (que é um pequeno detalhe), a coisa toda deve ser Y". Por exemplo: "A julgar até pela atitude dele (taido kara merda), ele é um profissional." Isso destaca um pequeno sinal revelador!
