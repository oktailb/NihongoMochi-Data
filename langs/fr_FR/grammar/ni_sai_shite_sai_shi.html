L'expression～に際して(にさいして) est utilisé pour indiquer un moment ou une occasion spécifique où quelque chose d'important est sur le point de se produire. c'est une expression très formelle, souvent utilisée dans les cérémonies, les discours officiels ou les avis écrits.
