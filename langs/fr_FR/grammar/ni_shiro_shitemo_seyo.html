Quel que soit le choix : ～にしろ / ～にしても / ～にせよ

Parfois, le résultat reste le même quel que soit le chemin que vous empruntez. Ces expressions signifient « même si », « que ce soit... ou... » ou « indépendamment de ». Ils sont utilisés pour montrer qu’une conclusion s’applique à plusieurs possibilités.

1. Structure des phrases

  • `Verbe/Adj (forme simple)` + にしろ / にしても / にせよ
  • `Noun` + にしろ / にしても / にせよ

2. Exemples universels

  • 行いく`にしても`行いかない`にしても`、早はやめに連絡れんらくしてください。
    (Que vous y alliez ou non, veuillez me contacter tôt.)
  • 冗談じょうだん`にしろ`、そんなことを言いうのはよくない。
    (Même si c'était une blague, ce n'est pas bien de dire une chose pareille.)
  • 忙いそがしい`にせよ`、食事しょくじはきちんと摂とるべきだ。
    (Même si vous êtes occupé, vous devriez manger correctement.)

3. Note de Sensei

Ces trois mots sont similaires, mais `～にせよ` est le plus formel, tandis que `～にしても` est le plus courant dans la vie quotidienne. Lorsque vous les utilisez par paires (A `に　しろ` B `に　しろ`), vous dites que le résultat est vrai à la fois pour A et B. C'est une excellente façon de montrer qu'une règle ou un conseil est inévitable !
