Du point de vue de : ～にしたら / ～にすれば / ～にしても

L'expression `～にしたら` (et ses variantes `～にすれば` ou `～にしても`) est utilisée pour exprimer une opinion ou un sentiment du point de vue de quelqu'un d'autre. Cela se traduit par "du point de vue de..." ou "même pour [quelqu'un]..."

1. Structure des phrases

Attachez ces expressions directement à un « nom » (généralement une personne ou un groupe).

`[Nom] + にしたら / にすれば / にしても`

  • 親おや`にしたら`、子供こども·将来しょうらいが一番いちばん心配しんぱいなのだ。
    (Du point de vue des parents, l'avenir de leur enfant est la plus grande préoccupation.)
  • かれ`にすれば`、ただの冗談じょうだんだったのだろうが、私わたしは傷きずついた。
    (De son point de vue, c’était probablement juste une blague, mais j’ai été blessé.)
  • プロの選手せんしゅ`にしても`、この試合しあいは緊張きんちょうするだろう。
    (Même pour un joueur professionnel, ce match serait angoissant.)

2. Nuance clé : empathie ou supposition

Il est souvent utilisé lorsque l'orateur essaie d'imaginer ou de souligner les sentiments de quelqu'un d'autre. `～にしても` ajoute la nuance de « même du point de vue de cette personne ».

3. Distinction avec ～にとって

  • `～にとって :` Exprime une évaluation ou une importance (Pour moi, c'est difficile).
  • `～にしたら :` Se concentre davantage sur les « pensées ou sentiments » internes du sujet (si vous étiez à leur place...).
