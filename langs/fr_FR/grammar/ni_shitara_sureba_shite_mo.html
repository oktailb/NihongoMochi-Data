Du point de vue de : ～にしたら / ～にすれば / ～にしても

L'expression～にしたら(et ses variantes～にすればou～にしても) est utilisé pour exprimer une opinion ou un sentiment du point de vue de quelqu'un d'autre. Cela se traduit par "du point de vue de..." ou "même pour [quelqu'un]..."

1. Structure des phrases

Attachez ces expressions directement à unNom(généralement une personne ou un groupe).

[Nom] + にしたら / にすれば / にしても

  • 親おやにしたら、子供こども·将来しょうらいが一番いちばん心配しんぱいなのだ。
    (Du point de vue des parents, l'avenir de leur enfant est la plus grande préoccupation.)
  • かれにすれば、ただの冗談じょうだんだったのだろうが、私わたしは傷きずついた。
    (De son point de vue, c’était probablement juste une blague, mais j’ai été blessé.)
  • プロの選手せんしゅにしても、この試合しあいは緊張きんちょうするだろう。
    (Même pour un joueur professionnel, ce match serait angoissant.)

2. Nuance clé : empathie ou supposition

Il est souvent utilisé lorsque l'orateur essaie d'imaginer ou de souligner les sentiments de quelqu'un d'autre.～にしても» ajoute la nuance « même du point de vue de cette personne ».

3. Distinction avec ～にとって

  • ～にとって :Exprime une évaluation ou une importance (Pour moi, c’est difficile).
  • ～にしたら :Se concentre davantage sur l'internepensées ou sentimentsdu sujet (Si vous étiez à leur place...).
