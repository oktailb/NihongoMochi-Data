"Même si" : ～ても

La conjonction～てもest utilisé pour exprimer une condition dans laquelle quelque chose se produit malgré tout. Cela se traduit par « même si » ou « même si ».

1. Structure des phrases

AttacherもauForme Tede verbes, d'adjectifs ou de noms.

  • Verbes : 雨あめが降ふっても、行いきます。
    (Même s'il pleut, j'y vais.)
  • い-Adj : 高たかくても、買かいたいです。
    (Même si c'est cher, je veux l'acheter.)
  • な-Adj / Noms : 嫌きらいでも、食たべなければなりません.
    (Même si vous le détestez, vous devez le manger.)

2. Phrase de question courante : ～てもいいですか

Cette structure est la base pour demander la permission (Puis-je... ?).

  • 入はいってもいいですか。(Est-ce que je peux entrer ?)
