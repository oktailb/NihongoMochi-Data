"Même si" : ～ても

La conjonction `～ても` est utilisée pour exprimer une condition dans laquelle quelque chose se produit malgré tout. Cela se traduit par « même si » ou « même si ».

1. Structure des phrases

Attachez « も » à la « forme Te » des verbes, adjectifs ou noms.

  • `Verbes :`雨あめが`降ふっても`、行いきます。
    (Même s'il pleut, j'y vais.)
  • `い-Adj :`高たか`くても`、買かいたいです。
    (Même si c'est cher, je veux l'acheter.)
  • `な-Adj / Noms :`嫌きらい`でも`、食たべなければなりません.
    (Même si vous le détestez, vous devez le manger.)

2. Phrase de question courante : ～てもいいですか

Cette structure est la base pour demander la permission (Puis-je... ?).

  • 入はいってもいいですか。(Est-ce que je peux entrer ?)
