Les bases de Keigo (敬語けいご)

« Keigo » est le système honorifique en japonais. Il est utilisé pour montrer le respect, la distance sociale et la politesse. Dans la société japonaise, le choix du bon niveau de Keigo dépend de votre interlocuteur et de votre statut social relatif.

1. Les trois types de Keigo

Keigo est divisé en trois catégories principales :

Catégorie Nom japonais Usage
« Poli » 丁寧語ていねいご Politesse générale envers quiconque (utilise `です/ます`).
« Honorifique » 尊敬語そんけいご Valoriser les actions d’un « supérieur » (patron, enseignant, client).
« Humble » 謙譲語けんじょうご Réduire « vos propres » actions pour montrer du respect à un supérieur.

2. Forme respectueuse (尊敬語そんけいご) Motifs

Ceci est utilisé pour parler de quelqu'un que vous respectez. Un modèle courant est le suivant :

`お + [Tige verbale] + になります`

  • 先生せんせいはもうお帰かえり`になりました`。
    (Le professeur est déjà rentré chez lui.)
  • チケットをお持もち`になっていますか`。
    (Avez-vous [personne honorée] votre billet ?)

3. Forme humble (謙譲語けんじょうご) Motifs

Ceci est utilisé lorsque vous parlez de vos propres actions dirigées vers un supérieur. Un modèle courant est le suivant :

`お + [Tige verbale] + します`

  • お荷物にもつをお持もち`します`。
    (Je porterai vos sacs [humblement].)
  • 明日あした、お電話でんわ`します`。
    (Je t'appellerai demain.)

4. Quand utiliser Keigo ?

Considérez-le comme un système « In-group/Out-group » (Uchi-Soto). Vous utilisez Keigo pour des personnes extérieures à votre cercle (clients, inconnus) ou des personnes de rang supérieur à vous (votre patron). Vous ne l'utilisez pas pour vous-même ou pour les membres de votre propre famille lorsque vous parlez à d'autres.
