Le pouvoir du but : ～ために (Pour / Afin de)

Que vous vous entraîniez pour devenir le prochain « ほかげ » ou que vous étudiiez pour réussir le JLPT, vous avez besoin d'un objectif. En japonais,ために est votre structure de prédilection pour exprimer le « but » ou le « bénéfice ». C'est le « pourquoi » derrière votre quête épique !

classe="exemple"> "Je m'entraîne" pour "protéger mes amis." — La motivation du héros classique.

1. Les deux visages de ために

En fonction de ce qui le précède,ために peut signifier deux choses légèrement différentes :

  • `Afin de :` Lorsqu'il est attaché à un verbe (Action).
  • « Pour le bien de : » Lorsqu'il est attaché à un nom (personne ou objectif).

2. Comment se connecter

C'est une connexion simple, mais la « colle » dépend du type de mot.

Type de mot Connexion Exemple
Verbes Formulaire de dictionnaire +ために 勝かつ`ために`
Noms Nom +の + ために 平和へいわ`のために`

3. Utilisation au combat (et dans la vie)

  • 日本にほんへ行いく`ために`、貯金ちょきんしています。
    (J'économise de l'argent « pour » aller au Japon.)
  • 家族かぞく`のために`、一生懸命いっしょうけんめい働はたらきます。
    (Je travaille dur « pour le bien » de ma famille.)

4. ために contre ように

Au cours de votre voyage, vous pourriez rencontrerように. Voici le secret pour les différencier :

  • `ために :` Utilisé pour les « actions contrôlées » (je « décide » de faire X pour atteindre Y).
  • `ように:` Utilisé pour les objectifs `potentiels/non contrôlés` (je fais X `pour que` Y puisse arriver).

classe="exemple"> `Sagesse de Sensei :` Utilisationために lorsque vous avez une cible claire en ligne de mire. C'est la marque d'un guerrier déterminé !

夢ゆめの`ために`頑張がんばろう ! (Faisons de notre mieux pour réaliser nos rêves !)
