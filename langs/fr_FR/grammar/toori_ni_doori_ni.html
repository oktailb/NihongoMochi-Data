Instructions suivantes : ～とおりに et ～どおりに

L'expression `～とおりに` est utilisée pour dire qu'une action est effectuée exactement comme quelque chose d'autre l'indique : en suivant un chemin, un ensemble d'instructions ou une pensée. Cela se traduit par "exactement comme...", "suivant..." ou "selon...".

1. Structure des phrases

La connexion dépend si vous utilisez un verbe ou un nom.

Avec des verbes (dictionnaire ou forme Ta)

  • 私わたしが言いった`とおりに`してください。
    (S'il vous plaît, faites « exactement » que j'ai dit.)
  • 説明書せつめいしょに書かいてある`とおりに`、組くみ立たてました。
    (Je l'ai assemblé "exactement comme" écrit dans le manuel.)

Avec des noms

Vous pouvez utiliser `Noun + の + とおり` ou la version vocale `Noun + どおり` (sans la particule `の`).

  • 地図ちず`のとおりに`行いけば、着つきます。
    (Si vous allez « selon » la carte, vous arriverez.)
  • 計画けいかく`どおりに`進すすんでいます。
    (Cela se déroule « selon » le plan.)

2. Tableau de connexion

Taper Connexion
Verbes Forme simple + `とおりに`
Noms (Méthode 1) Nom + `の` + `とおりに`
Noms (méthode 2) Nom + `どおりに`

3. Expressions courantes

  • 思おもったとおり (Exactement comme je le pensais)
  • 期待きたいどおり (Comme prévu)
  • 命令めいれいどおり (Comme commandé)
