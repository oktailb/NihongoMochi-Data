D'un certain point de vue : ～からいうと / ～からいえば

La façon dont nous voyons les choses dépend de notre position !～からいうと(et ses variantes) est utilisé pour exprimer une opinion ou un jugement d’un point de vue spécifique. Cela signifie « du point de vue de… » ou « à en juger par… »

1. Structure des phrases

Nom+ からいうと / からいえば / からいって

2. Exemples de perspectives

  • 能力のうりょくからいうと、彼かれが一番いちばんふさわしい。
    (Du point de vue de ses capacités, il est le [candidat] le plus approprié.)
  • 今いま·実力じつりょくからいえば、合格ごうかくは難むずかしいだろう。
    (À en juger par son niveau actuel de capacité, réussir sera probablement difficile.)
  • 私の経験けいけんからいってそれはあまりおすすめしません.
    (Parlant de mon expérience, je ne le recommanderais pas vraiment.)

3. Note de Sensei

Les variantes sont similaires :～からいうとse concentre sur le point de vue lui-même,～からいえばest souvent utilisé pour une conclusion ou un jugement conditionnel, et～からいってest fréquemment utilisé pour motiver une opinion. Tous vous aident à ancrer votre déclaration dans un contexte spécifique !
