Le radical du verbe (連用形れんようけい)

Le « radical verbal » (également appelé « radical masu » ou « base 2 ») est l'élément de base le plus fondamental de la conjugaison japonaise. Une fois que vous connaissez le radical, vous pouvez attacher des dizaines de terminaisons différentes pour changer le sens du verbe.

1. Comment former la tige

Groupe 1 : Verbes U (Godan)

Remplacez le son « u » final du formulaire de dictionnaire par le son « i » correspondant.

  • 買か`う` →買か`い`
  • 聞き`く` →聞き`き`
  • 話はな`す` →話はな`し`
  • 遊あそ`ぶ` →遊あそ`び`

Groupe 2 : Verbes Ru (Ichidan)

Supprimez simplement le « る » final.

  • 食たべ`る` →食た`べ`
  • 見み`る` →見み
  • 寝ね`る` →寝ね

Groupe 3 : Verbes irréguliers

Mémorisez ces deux-là :

  • する → `し`
  • 来くる (kuru) → `来き` (ki)

2. Pourquoi le Stem est-il important ?

La tige est utilisée pour créer de nombreuses formes communes. Voici quelques exemples que vous apprendrez :

  • `Tige + ます :` Forme polie (行いきます)
  • `Tige + たい :` Exprimer le désir (行いきたい)
  • `Stem + ながら :` Actions simultanées (歩ある(きながら)
  • `Stem + すぎる :` En faire trop (食た(べすぎる)
  • `Stem + なさい :` Donner un ordre (飲のみなさい)

3. Utilisation formelle

Dans l'écriture formelle, le radical peut être utilisé seul pour relier deux phrases, un peu comme la « forme Te ».
