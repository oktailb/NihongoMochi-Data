Le radical du verbe (連用形れんようけい)

LeTige du verbe(également appelé leTige MasuouBase 2) est l’élément le plus fondamental de la conjugaison japonaise. Une fois que vous connaissez le radical, vous pouvez attacher des dizaines de terminaisons différentes pour changer le sens du verbe.

1. Comment former la tige

Groupe 1 : Verbes U (Godan)

Changer la finale"tu"son de la forme du dictionnaire au correspondant"je"son.

  • 買か· → 買かい
  • 聞きく → 聞きき
  • 話はなす → 話はなし
  • 遊あそぶ → 遊あそび

Groupe 2 : Verbes Ru (Ichidan)

Supprimez simplement la finaleる.

  • 食たべる → 食たべ
  • 見みる → 見み
  • 寝ねる → 寝ね

Groupe 3 : Verbes irréguliers

Mémorisez ces deux-là :

  • する →し
  • 来くる (kuru) →来き(ki)

2. Pourquoi le Stem est-il important ?

La tige est utilisée pour créer de nombreuses formes communes. Voici quelques exemples que vous apprendrez :

  • Tige + ます :Forme polie (行いきます)
  • Tige + たい :Exprimer le désir (行いきたい)
  • Tige + ながら :Actions simultanées (歩ある(きながら)
  • Tige + すぎる :En faire trop (食た(べすぎる)
  • Tige + なさい :Donner un ordre (飲のみなさい)

3. Utilisation formelle

Dans l'écriture formelle, le radical peut être utilisé seul pour relier deux phrases, un peu comme leForme Te.
