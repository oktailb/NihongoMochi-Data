État résultant : ～てある

L'expression `～てある` est utilisée pour décrire un état qui existe à la suite d'une action intentionnelle effectuée par quelqu'un. Cela implique souvent que quelqu’un a fait quelque chose dans un but précis, et le résultat est toujours visible.

1. Structure des phrases

Attachez `ある` au `て形` d'un `verbe transitif` (un verbe qui prend un objet, comme « ouvrir » ou « écrire »).

`[Objet] が + [Verbeて形てけい] + ある`

  • 窓まどが`開あけてあります`。
    (La fenêtre a été ouverte [et est toujours ouverte].)
  • カレンダーに予定よていが`書かいてあります`。
    (L'horaire a été inscrit sur le calendrier.)

2. ～てある contre ～ている

Si les deux décrivent un état, la nuance est différente :

  • `～ている :` Décrit simplement un état ou une action en cours (par exemple, « La fenêtre est ouverte »). Il ne se concentre pas sur « qui » ​​ou « pourquoi ».
  • `～てある :` Se concentre sur le fait que quelqu'un l'a fait "exprès" (par exemple, "Quelqu'un a ouvert la fenêtre pour une raison").

3. Utilisation avec préparation

Il est souvent utilisé lorsque les préparatifs sont terminés.

  • 料理りょうりはもう`作つくってあります`。
    (La nourriture a déjà été préparée [pour les invités].)

4. Astuce rapide

Si vous voyez la particule `が` avec un verbe transitif dans la combinaison `て形` + `ある`, il s'agit presque certainement de cette grammaire de « l'état résultant » !
