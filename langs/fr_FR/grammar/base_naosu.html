A refaire pour corriger : ～なおす

Le suffixe `～なおす` est utilisé pour indiquer qu'une action est « refaite », généralement dans le but d'améliorer le résultat ou de corriger une erreur.

1. Note pédagogique

Il est similaire au préfixe anglais « re- » (refaire, relire), mais met spécifiquement l'accent sur « l'amélioration, la correction ou un nouveau départ ». Si vous avez fait une erreur la première fois, vous utilisez `~なおす` pour la corriger.

2. Structure des phrases

  • Verbe (tige ~ます) + `なおす`

3. Exemples

  • もう一度いちど考かんがえ`なおして`ください。
    (Veuillez reconsidérer [pensez-y à nouveau].)
  • テストを書かき`なおしました`。
    (J'ai réécrit le test [pour corriger les erreurs].)
  • 読よみ`なおすと`、間違いがよくわかります。
    (Quand vous le relisez, vous pouvez facilement trouver les erreurs.)
