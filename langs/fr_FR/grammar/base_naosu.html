A refaire pour corriger : ～なおす

Le suffixe～なおすest utilisé pour indiquer qu’une action estrefait, généralement avec l'intention d'améliorer le résultat ou de corriger une erreur.

1. Note pédagogique

Il est similaire au préfixe anglais « re- » (refaire, relire), mais souligne spécifiquementamélioration, correction ou nouveau départ. Si vous avez fait une erreur la première fois, vous utilisez~naosupour le réparer.

2. Structure des phrases

  • Verbe (tige -masu) +なおす

3. Exemples

  • もう一度いちど考かんが·なおしてください。
    (Veuillez reconsidérer [pensez-y à nouveau].)
  • テストを書かきなおしました。
    (J'ai réécrit le test [pour corriger les erreurs].)
  • 読よみなおすと、間違いがよくわかります。
    (Quand vous le relisez, vous pouvez facilement trouver les erreurs.)
