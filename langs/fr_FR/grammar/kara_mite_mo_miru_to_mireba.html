Du point de vue de : ～から見ても / ～から見ると / ～から見れば

L'expression `～から見ると` (et ses variantes `～から見れば` ou `～から見ても`) est utilisée pour exprimer un jugement ou une observation d'un point de vue spécifique. Cela se traduit par « du point de vue de… », « vu de… » ou « en regardant… »

1. Structure des phrases

Attachez ces expressions directement à un « nom » (une personne, un groupe ou un concept abstrait).

`[Nom] + から見ると / から見れば / から見ても`

  • 教師きょうし`から見れば`、かれはとてもまじめな学生がくせいです。
    (Du point de vue d'un enseignant, c'est un élève très sérieux.)
  • 外国人がいこくじん`から見ると`、日本にほん·物価ぶっかは高たかいと感かんじるかもしれない。
    (Du point de vue d'un étranger [étranger], ils pourraient avoir l'impression que les prix au Japon sont élevés.)
  • かれの実力じつりょく`から見れば`、このテストは簡単かんたんすぎるはずだ。
    (Du point de vue de ses capacités réelles, ce test devrait être trop facile.)

2. Nuance clé : observation basée sur la position

Contrairement à `~に　したら` (empathie), `～から見ると` se concentre sur « l'observation objective » faite à partir d'une certaine position ou catégorie.

3. Distinction avec ～からすると

  • `～からすると :` Met l'accent sur les « preuves ou indices » utilisés pour faire une supposition.
  • `～から見ると :` Met l'accent sur le « point de vue ou l'angle » à partir duquel quelque chose est vu.
