Du point de vue de : ～から見ても / ～から見ると / ～から見れば

L'expression～から見ると(et ses variantes～から見ればou～から見ても) est utilisé pour exprimer un jugement ou une observation d’un point de vue ou d’une perspective spécifique. Cela se traduit par "du point de vue de...", "vu de..." ou "regardant..."

1. Structure des phrases

Attachez ces expressions directement à unNom(une personne, un groupe ou un concept abstrait).

[Nom] + から見ると / から見れば / から見ても

  • 教師きょうしから見れば、かれはとてもまじめな学生がくせいです。
    (Du point de vue d'un enseignant, c'est un élève très sérieux.)
  • 外国人がいこくじんから見ると、日本にほん·物価ぶっかは高たかいと感かんじるかもしれない。
    (Du point de vue d'un étranger [étranger], ils pourraient avoir l'impression que les prix au Japon sont élevés.)
  • かれの実力じつりょくから見ればこのテストは簡単かんたんすぎるはずだ。
    (Du point de vue de ses capacités réelles, ce test devrait être trop facile.)

2. Nuance clé : observation basée sur la position

Contrairement à~ni merde(empathie),～から見るとse concentre sur leobservation objectivefait à partir d’une certaine position ou catégorie.

3. Distinction avec ～からすると

  • ～からすると :Souligne ledes preuves ou des indicesutilisé pour faire une supposition.
  • ～から見ると :Souligne lepoint de vue ou angleà partir duquel quelque chose est vu.
