Câu điều kiện -Tara (~たら)

The ~tara conditional is the most common and versatile way to say "if" or "when" in Japanese. It is used to describe a condition that must be met before another action can happen.

1. Cách liên hợp

The rule is simple: Take the Ta-dạng (informal past) of a verb, adjective, or noun, and add ら (ra).

Động từ

  • 行く (iku - to go) → 行った (itta) → 行ったら (ittara) - If I go / When I go
  • 食べる (taberu - to eat) → 食べた (tabeta) → 食べたら (tabetara) - If I eat / When I eat
  • する (suru - to do) → した (shita) → したら (shitara) - If I do

tính từ

  • I-Tính từ: Replace the final ~i with ~katara.
    安い (yasui - cheap) → 安かったら (yasukattara) - If it is cheap.
  • Na-Tính từ: Add ~dattara.
    暇 (hima - free time) → 暇だったら (hima dattara) - If you are free.

Danh từ

Like Na-adjectives, add ~dattara.

  • 雨 (ame - rain) → 雨だったら (ame dattara) - If it rains.

2. Khi nào nên sử dụng?

  1. Giả thuyết "Nếu": When something might happen.
    お金があったら、車を買います。(Okane ga attara, kuruma wo kaimasu) - If I had money, I would buy a car.
  2. "Khi nào" tạm thời: When the condition is certain to happen in the future.
    家に着いたら、電話して。(Ie ni tsuitara, denwa shite) - When you get home, call me.

3. Lưu ý quan trọng

The event in the ~tara clause must happen Đầu tiên. You cannot use ~tara for things happening at the same time.
