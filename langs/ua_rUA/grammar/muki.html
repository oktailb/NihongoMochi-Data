Підходить для завдання: ～向き (むき)

Поки~мукайдеться про "намір",～向きйдеться про "придатність". Це означає, що щось природно підходить для певної особи чи певної мети, незалежно від того, було це спочатку розроблено для них чи ні. Це означає «придатний для» або «придатний для».

1. Будова речення

Іменник+ 向き (だ / に / の + іменник)

2. Відповідні приклади

  • この仕事しごとは彼かれ向きだ。
    (Ця робота йому підходить / Він підходить для цієї роботи.)
  • この服ふくは夏なつ向きの素材そざいでできている。
    (Цей одяг виготовлено з матеріалу, придатного для літа.)
  • ここは初心者しょしんしゃ向きのコースです。
    (Цей курс підходить для початківців.)

3. Записка Сенсея

Пам'ятайте:向け= "Я зробив це для вас."向き= "Це ідеально для вас." Наприклад, «дитяче меню».кодомо-муке, але маленьке, легке крісло може бутикодомо-мукитому що це правильний розмір для них!
