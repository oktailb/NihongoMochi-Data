Основа дієслова (連用形れんようけい)

TheОснова дієслова(також називаєтьсяМасу-стеблоабоОснова 2) є найбільш фундаментальним будівельним блоком у японському відмінюванні. Коли ви дізнаєтеся основу, ви можете додати десятки різних закінчень, щоб змінити значення дієслова.

1. Як сформувати стебло

Група 1: U-дієслова (Годан)

Змінити фінал"у"звучання словникової форми на відповід"я"звук.

  • 買かう → 買かい
  • 聞きく → 聞きき
  • 話はなす → 話はなし
  • 遊あそぶ → 遊あそび

Група 2: Ru-дієслова (Ічідан)

Просто видаліть фіналる.

  • 食たべる → 食たべ
  • 見みる → 見み
  • 寝ねる → 寝ね

3 група: Неправильні дієслова

Запам'ятайте ці два:

  • する →し
  • 来くる (куру) →来き(кі)

2. Чому стебло важливе?

Стебло використовується для створення багатьох поширених форм. Ось кілька прикладів, які ви дізнаєтеся:

  • Стебло + ます:Ввічлива форма (行いきます)
  • Стебло + たい:Висловлення бажання (行いきたい)
  • Стебло + ながら:Одночасні дії (歩あるきながら)
  • Стебло + すぎる:робити занадто багато (食たべすぎる)
  • Стебло + なさい:Надання замовлення (飲のみなさい)

3. Офіційне використання

У офіційному письмі основа може використовуватися сама по собі для зв’язку двох речень, подібно доТе-форма.
