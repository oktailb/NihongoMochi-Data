Потенційна форма (可能形) – «можу»

The Потенційна форма is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. Сполучення

Група 1: U-дієслова (Годан)

Change the final "у" sound to the "е" sound and add る (ru).

  • 行く (iku - go) → 行け + る = 行ける (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 話せる (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲める (nomeru) - Can drink

Група 2: Ru-дієслова (Ічідан)

Replace the final る (ru) with られる (рідкісний).

  • 食べる (taberu) → 食べられる (taberareru) - Can eat
  • 見る (miru) → 見られる (mirareru) - Can see

Примітка. У невимушеній мові "ра" часто опускається: 食べれる (tabereru).

3 група: Неправильні дієслова

  • する (suru) → できる (dekiru) - Can do (Зовсім інший!)
  • 来る (kuru) → 来られる (korareru) - Can come

2. Важлива зміна частинок

When using the potential form, the object particle を (wo) often changes to が (ga).

  • 日本語を話します。(Я розмовляю японською.)
  • 日本語が話せます。(I може speak Japanese.)

3. «Потенційна форма» проти «~koto ga dekiru»

Both mean "can do", but the potential form is more common in daily conversation, while кото га декіру is slightly more formal or used for long verb phrases.
