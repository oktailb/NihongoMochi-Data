-Tara Conditional (~たら)

The ~тара conditional is the most common and versatile way to say "if" or "when" in Japanese. It is used to describe a condition that must be met before another action can happen.

1. Сполучення

The rule is simple: Take the Та-форма (informal past) of a verb, adjective, or noun, and add ら (ra).

Дієслова

  • 行く (iku - to go) → 行った (itta) → 行ったら (ittara) - If I go / When I go
  • 食べる (taberu - to eat) → 食べた (tabeta) → 食べたら (tabetara) - If I eat / When I eat
  • する (suru - to do) → した (shita) → したら (shitara) - If I do

Прикметники

  • Я-прикметники: Replace the final ~i with ~каттара.
    安い (yasui - cheap) → 安かったら (yasukattara) - If it is cheap.
  • Na-прикметники: Add ~даттара.
    暇 (hima - free time) → 暇だったら (hima dattara) - If you are free.

Іменники

Like Na-adjectives, add ~даттара.

  • 雨 (ame - rain) → 雨だったら (ame dattara) - If it rains.

2. Коли це використовувати?

  1. Гіпотетичне «якщо»: When something might happen.
    お金があったら、車を買います。(Okane ga attara, kuruma wo kaimasu) - If I had money, I would buy a car.
  2. Тимчасове «Коли»: When the condition is certain to happen in the future.
    家に着いたら、電話して。(Ie ni tsuitara, denwa shite) - When you get home, call me.

3. Важливе зауваження

The event in the ~тара clause must happen перший. You cannot use ~тара for things happening at the same time.
