Подача команд: ～なさい

The～なさいформа використовується для надання твердого наказу чи вказівки. Хоча це граматично ввічливість (походить від почесногоnasaru), він несе сильний авторитетний тон. Його зазвичай використовують батьки для дітей, вчителі для студентів або в письмових інструкціях до іспиту.

1. Сполучення

Прикріпітьなさいбезпосередньо доОснова дієслова(частина перед~масу).

[Основа дієслова] + なさい

  • 食たべます →食たべ + なさい =食たべなさい(Їсти!)
  • 行いきます →行いき + なさい =行いきなさい(Йди!)
  • します → し + なさい =しなさい(Зроби це!)

2. Основні приклади

  • 「もう遅おそいから、早はやく寝ねなさい。」
    («Вже пізно, значитьіди спатишвидко.")
  • 「テレビを消けして、宿題しゅくだいをしなさい。」
    («Вимкніть телевізор іробититвоє домашнє завдання").
  • 「つぎの質問しつもんに答こたえなさい。」
    ("Відповідьнаступне запитання»).

3. Нюанс: Коли НЕ використовувати

Тому що～なさいмає на увазі чітку ієрархію, де оратор має владу над слухачем, ви повиннініколивикористовуйте його по відношенню до начальника (начальника, вчителя) або незнайомої людини. У таких випадках використовуйте～てくださいдля запитів.

4. Коротка порада: ～なさい проти ～ろ (наказовий спосіб)

  • ～なさい:Твердий і авторитетний, але використовується в «виправній» або виховній формі (батьки, вчителі).
  • ～ろ (Імперативна форма):Дуже грубий, агресивний або використовується в надзвичайних ситуаціях. Це звучить набагато жорсткіше, ніж~насай.
