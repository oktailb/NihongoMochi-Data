Най-форма (ない形) – неформальний негатив

The Най-форма is used for the negative present tense in casual Japanese. It is also the building block for several important grammar structures like "must" or "please don't".

1. Сполучення

Відмінювання залежить від дієслівної групи. Зверніть увагу на групу 1!

Група 1: U-дієслова (Годан)

Change the final "у" sound of the dictionary form to the corresponding "а" sound, then add ない.

  • 書く (kaku) → 書か + ない = 書かない (kakanai) - Not write
  • 飲む (nomu) → 飲ま + ない = 飲まない (nomanai) - Not drink
  • 話す (hanasu) → 話さ + ない = 話さない (hanasanai) - Not speak

⚠️ Спеціальне правило: If the verb ends in a plain う (у), it changes to わ (ва), not 'a'.

  • 買う (kau) → 買わ + ない = 買わない (kawanai) - Not buy

Група 2: Ru-дієслова (Ічідан)

Simply drop the final る (ru) and add ない.

  • 食べる (taberu) → 食べない (tabenai) - Not eat
  • 見る (miru) → 見ない (minai) - Not see

3 група: Неправильні дієслова

Уважно запам’ятайте їх (зверніть увагу на зміну звуку для «куру»):

  • する (suru) → しない (shinai)
  • 来る (kuru) → 来ない (konai - pronounced ко-най)
  • ある (aru - to exist/have) → ない (nai) (Зовсім ненормально!)

2. Загальні граматичні моделі

Най-форма необхідна для цих основних структур:

  1. Прохання нічого не робити (~naide kudasai):
    忘れないでください。(Wasurenaide kudasai) - Please don't forget.
  2. Зобов'язання (~nakereba narimasen): "Must do" (lit: If you don't do, it's no good).
    勉強しなければなりません。(Benkyou shinakereba narimasen) - I must study.
  3. Робити щось, не роблячи іншого (~zuni / ~naide):
    寝ないで勉強しました。(Nenaide benkyou shimashita) - I studied without sleeping.
