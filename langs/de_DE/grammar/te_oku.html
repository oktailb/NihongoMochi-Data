Im Voraus erledigen:

Das Hilfsverb „～ておく“ wird verwendet, wenn Sie eine Aktion „im Voraus“ ausführen, um sich auf die Zukunft vorzubereiten oder einen bestimmten Zustand so beizubehalten, wie er ist.

1. Vorbereitung auf die Zukunft

Machen Sie jetzt etwas, damit Sie sich später keine Sorgen mehr machen müssen.

  • 旅行りょこうの前まえに、ホテルを`予約よやくしてtolle きます`.
    (Ich werde vor der Reise im Voraus ein Hotel buchen.)
  • 明日あしたテストがあるから、`勉強べんきょうしてtolle きます`.
    (Da morgen ein Test ist, werde ich im Voraus lernen.)

2. Einen Staat so lassen, wie er ist

Manchmal bedeutet es, etwas zu tun, um eine Situation aufrechtzuerhalten.

  • 窓まどを`開あけて て て く だ さ い.
    (Bitte lassen Sie das Fenster offen [lassen Sie es so].)

3. Lässige Form: ～とく

In der lockeren Sprache wird „～てく“ oft zu „～とく“ verkürzt.

  • ～てkamく → `～とく` (z. B.書かいとく)
  • ～でおく → `～どく` (z. B.飲のんどく)

`Beispiel:` ビール、買かいとくね！ (Ich kaufe das Bier im Voraus! [Casual])
