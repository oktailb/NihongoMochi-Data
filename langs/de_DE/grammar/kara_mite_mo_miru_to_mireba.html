Aus der Sicht von: ～から見ても / ～から見ると / ～から見れば

Der Ausdruck „～から見ると“ (und seine Varianten „～から見れば“ oder „～から見ても“) wird verwendet, um ein Urteil oder eine Beobachtung aus einer bestimmten Perspektive oder einem bestimmten Standpunkt auszudrücken. Übersetzt bedeutet es „vom Standpunkt aus gesehen“, „von … aus gesehen“ oder „betrachtet …“.

1. Satzstruktur

Hängen Sie diese Ausdrücke direkt an ein „Substantiv“ (eine Person, eine Gruppe oder ein abstraktes Konzept) an.

`[Substantiv] + から見ると / から見れば / から見ても`

  • 教師きょうし`から見れば`、かれはとてもまじめな学生がくせいです.
    (Aus der Sicht eines Lehrers ist er ein sehr ernsthafter Schüler.)
  • 外国人がいこくじん`から見ると`、日本にほんの物価ぶっかは高たかいと感かんじるかもしれない.
    (Aus der Sicht eines Außenstehenden [Ausländers] könnten sie das Gefühl haben, dass die Preise in Japan hoch sind.)
  • かれの実力じつりょく„から見れば`, このテストは簡単かんたんすぎるはずだ.
    (Aus der Sicht seiner tatsächlichen Fähigkeiten dürfte dieser Test zu einfach sein.)

2. Schlüsselnuance: Beobachtung basierend auf der Position

Im Gegensatz zu „~に　したら“ (Empathie) konzentriert sich „～から見ると“ auf die „objektive Beobachtung“, die von einer bestimmten Position oder Kategorie aus erfolgt.

3. Unterscheidung von ～からすると

  • „～からすると:“ Betont die „Beweise oder Hinweise“, die für eine Vermutung verwendet werden.
  • „～から見ると:“ Betont den „Standpunkt oder Winkel“, von dem aus etwas betrachtet wird.
