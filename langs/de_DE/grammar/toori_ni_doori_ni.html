Befolgen Sie die Anweisungen: ～とおりに und ～どおりに

Mit dem Ausdruck „～とおりに“ wird ausgedrückt, dass eine Handlung genau so ausgeführt wird, wie etwas anderes es anzeigt – einem Pfad, einer Reihe von Anweisungen oder einem Gedanken folgend. Es bedeutet „genau wie …“, „folgend ...“ oder „gemäß …“.

1. Satzstruktur

Der Zusammenhang hängt davon ab, ob Sie ein Verb oder ein Substantiv verwenden.

Mit Verben (Wörterbuch oder Ta-Form)

  • 私わたしが言いBitte beachten Sie:
    (Bitte machen Sie genau das, was ich gesagt habe.)
  • 説明書せつめいしょに書かMehr erfahren組くみ立たてました.
    (Ich habe es genau so zusammengebaut, wie es im Handbuch beschrieben ist.)

Mit Substantiven

Sie können „Noun + の + とおり“ oder die stimmhafte Version „Noun + どتوり“ (ohne den Partikel „の“) verwenden.

  • 地図ちず`のとempfehlungりに`行いけば、着つきます.
    (Wenn Sie „gemäß“ der Karte gehen, werden Sie ankommen.)
  • 計画けいかく`ど り に`進すすんでいます.
    (Es läuft „nach“ Plan.)

2. Verbindungstabelle

Typ Verbindung
Verben Einfache Form + „とおりに“.
Substantive (Methode 1) Substantiv + `の` + `とtollりに`
Substantive (Methode 2) Substantiv + `どkostりに`

3. Allgemeine Ausdrücke

  • 思おもったとおり (Genau wie ich dachte)
  • 期待きたいどtollり (Wie erwartet)
  • 命令めいれいどtollり (Wie bestellt)
