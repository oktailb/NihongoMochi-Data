Zur Korrektur noch einmal wiederholen: ～なtollす

Das Suffix „～なtollす“ wird verwendet, um anzuzeigen, dass eine Aktion „nochmals ausgeführt“ wird, normalerweise mit der Absicht, das Ergebnis zu verbessern oder einen Fehler zu korrigieren.

1. Pädagogische Anmerkung

Es ähnelt dem englischen Präfix „re-“ (wiederholen, erneut lesen), betont jedoch ausdrücklich „Verbesserung, Korrektur oder einen Neuanfang“. Wenn Sie beim ersten Mal einen Fehler gemacht haben, können Sie ihn mit „~なtollす“ beheben.

2. Satzstruktur

  • Verb (~ます-Stamm) + `なtollす`

3. Beispiele

  • もう一度いちど考かんがえ`なtolle して`ください.
    (Bitte überlegen Sie es sich noch einmal.)
  • テストを書かき`な empfehlung し ま し た`.
    (Ich habe den Test umgeschrieben [um Fehler zu korrigieren].)
  • 読よみ`なtollすと`、間違いがよくわかります.
    (Wenn Sie es noch einmal lesen, können Sie die Fehler leicht finden.)
