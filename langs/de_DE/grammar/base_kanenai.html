Risiko von: ～かねない

Das Suffix „～かねない“ wird verwendet, um auszudrücken, dass die Möglichkeit oder das Risiko besteht, dass ein „negatives Ergebnis“ eintritt. Übersetzt bedeutet es „könnte passieren“, „könnte möglicherweise …“ oder „es besteht die Gefahr, dass ...“

1. Satzstruktur

Hängen Sie „かねない“ an den „Verbstamm“ an (den Teil vor „~ます“).

`[Verbstamm] + かねない`

  • そんなにスピードを出だすと、事故じこを起おこし`かねない`.
    (Wenn Sie so schnell fahren, könnten Sie „möglicherweise“ einen Unfall verursachen.)
  • あまり無理むりをすると、病気びょうきになり`かねません`よ.
    (Wenn Sie sich zu sehr überanstrengen, besteht die Gefahr, dass Sie krank werden.)
  • うっかりしていると、秘密ひみつを漏もらし`かねない`.
    (Wenn Sie unvorsichtig sind, könnten Sie möglicherweise das Geheimnis preisgeben.)

2. Schlüsselnuance: Negative Vorhersage

Im Gegensatz zu „～かもしれない“ (das neutral ist) wird „～かねない“ fast ausschließlich für unerwünschte Situationen verwendet. Dies impliziert, dass eine Katastrophe oder ein Fehler wahrscheinlich ist, wenn das aktuelle Verhalten anhält.

3. Verbindungsbeispiel

Verb Stängel „Gefahr von…“
起おこす 起おこし 起おこしかねない
なる なり なりかねない
