Erwartung: ～はず

Die Struktur „～はず“ wird verwendet, um eine Erwartung auszudrücken, die auf objektiven Gründen oder logischen Schlussfolgerungen basiert. Es bedeutet „es wird erwartet, dass…“ oder „es sollte der Fall sein, dass…“

1. Satzstruktur

Hängen Sie „はず“ an die „einfache Form“ von Verben und Adjektiven an. Verwenden Sie für Substantive „の“.

  • `Verben:`来くる`はず`です (Es wird erwartet, dass er kommt / Er sollte kommen).
  • `い-Adj:`美味おいしい`はず`です (Es sollte köstlich sein).
  • `な-Adj:`暇ひま`なはず`です (Er sollte frei sein).
  • „Substantive:“.今日きょう`のはず`です (Es sollte heute sein).

2. Schlüsselbeispiele

  • 田中たなかさんは今日きょう、来くる`はず`です.
    (Herr Tanaka soll heute kommen [z. B. weil er es gesagt hat].)
  • この薬くすりを飲のめば、良よくなる`はず`です.
    (Wenn Sie dieses Arzneimittel einnehmen, sollte es Ihnen besser gehen.)

3. Negative Erwartung: Nein

Um zu sagen, dass etwas „unmöglich“ ist oder „nicht der Fall sein kann“, verwenden Sie „はずがない“.

  • そんな`はずがありません`！
    (Das kann nicht möglich sein!)
  • あの真面目まじめな田中たなかさんが嘘うそをつく`はずがありません`.
    (Es ist unmöglich, dass der ernsthafte Herr Tanaka lügt.)

4. Nuancenhinweis

„～はず“ bedeutet, dass Sie einen bestimmten Grund für Ihren Glauben haben. Wenn Sie nur ohne triftigen Grund raten, verwenden Sie stattdessen „～でしょう“ oder „～かもしれない“.
