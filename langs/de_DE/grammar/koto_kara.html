Ursprung und Grund: ～ことから

Der Ausdruck „～ことから“ wird verwendet, um den Grund oder Ursprung eines Namens, eines Urteils oder einer Erkenntnis anzugeben. Übersetzt bedeutet es „aus der Tatsache, dass…“ oder „wegen…“

1. Herkunft eines Namens oder Status

Verwenden Sie dies, wenn Sie erklären, warum etwas auf eine bestimmte Weise bezeichnet wird oder wie eine Situation entstanden ist.

  • 富士山ふじさんがきれいな`ことから`、この町まちは「ふじみ町まち」と呼よばれている.
    (Da der Berg Fuji wunderschön ist, wird diese Stadt „Fujimi-machi“ genannt.)

2. Grundlage für ein Urteil

Verwenden Sie dies, wenn Sie aufgrund einer bestimmten Beobachtung zu einer Schlussfolgerung gelangen.

  • 道みちが濡ぬれている`ことから`、雨あめが降ふったことがわかる.
    (An der Tatsache, dass die Straße nass ist, kann man erkennen, dass es geregnet hat.)
  • ちょっとした誤解ごかい`ことから`、けんかになってしまった.
    (Aus einem kleinen Missverständnis wurde ein Kampf.)

3. Verbindungstabelle

Typ Verbindung
Verben / い-Adj Einfache Form + „ことから“.
な-Adj Adj + „な“ + „ことから“.
Substantive Substantiv + „である“ + „ことから“ (oder einfach Substantiv + „から“)
