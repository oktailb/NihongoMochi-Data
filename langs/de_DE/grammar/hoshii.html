Etwas wollen: ～ほしい

Das Adjektiv „ほしい“ (geschrieben als „欲しい“) wird verwendet, um auszudrücken, dass Sie ein Objekt möchten oder dass Sie möchten, dass jemand anderes etwas für Sie tut.

1. Ein Objekt wollen

Markieren Sie mit dem Partikel „が“ das gewünschte Objekt.

`[Objekt] が ほしいです`

  • 新あたらしい車くるま`がほしい`です.
    (Ich möchte ein neues Auto.)
  • プレゼントは何`がほしい`ですか.
    (Was wünschen Sie sich als Geschenk?)

2. Ich möchte, dass jemand etwas tut

Verwenden Sie die „Te-Form“ eines Verbs, gefolgt von „ほしい“.

`[Verbて形てけい] + ほしい`

  • 一緒いっしょに来き`てほしい`です.
    (Ich möchte, dass du mit mir kommst.)
  • 日本語にほんごを教おしえ`てほしい`んですが.
    (Ich möchte, dass Sie mir Japanisch beibringen [höfliche Bitte].)

3. Konjugation

„ほしい“ ist ein „Ich-Adjektiv“.

  • „Negativ:“.欲ほしくない (Ich will nicht)
  • `Vergangenheit:`欲ほしかった (Gesucht)

4. Warnung: Egozentrisch

Genau wie „～たい“ wird „ほしい“ im Allgemeinen nur für die eigenen Wünsche des Sprechers verwendet. Um zu beschreiben, was jemand anderes will, verwenden Sie „～ほしがっている“ (siehe Form „がる“).
