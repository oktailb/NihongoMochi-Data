Vollständig beenden: ～きれる / ～きれない

Das Suffix „～きる“ (vollständig beenden) wird in seiner potentiellen Form zu „～きれる“. Damit wird ausgedrückt, dass eine Handlung aufgrund ihres Umfangs oder ihrer Schwierigkeit bis zum Ende beendet werden kann oder nicht.

1. Satzstruktur

Hängen Sie „きれる“ oder „きれない“ an den „Verbstamm“ an.

  • こんなにたくさんの料理りょうりは、一人ひとりでは`食たべきれません`.
    (Ich kann das ganze Essen nicht alleine aufessen.)
  • かれは一晩ひとばんでその本ほんを`読よみきった`.
    (Er hat das ganze Buch an einem Abend zu Ende gelesen.)
  • 数かずえ`きれない`ほどたくさんの星ほしが見みえます.
    (Ich kann so viele Sterne sehen, dass sie unzählbar sind [kann das Zählen nicht beenden].)

2. Gebräuchliche Verben

Verb Bedeutung
使つかいきる Zum vollständigen Aufbrauchen
走はしいきる Die ganze Distanz laufen
信しんじきる Vollständig / ohne Zweifel glauben
