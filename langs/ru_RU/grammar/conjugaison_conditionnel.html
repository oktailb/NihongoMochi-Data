Условное сопряжение (仮定形かていけい)

The ～ばФорма используется для создания условных предложений (если...). Освоение его формирования необходимо для сложных грамматических моделей, таких как «чем больше... тем больше...».

1. Глаголы

Группа 1: У-глаголы (Годан)

Изменить финал"ты"звук соответствующий"е"озвучить и добавитьば.

  • 行いく → 行いけば
  • 話はなす → 話はなせば
  • 飲のむ → 飲のめば

Группа 2: Ру-глаголы (Ичидан)

Заменить финалるсれば.

  • 食たべる → 食たべれば
  • 見みる → 見れば

Группа 3: Неправильные глаголы

  • する →すれば
  • 来くる →来くれば(произноситсяКуреба)

2. Прилагательные

Я-прилагательные

Заменить финал～いс～ければ.

  • 暑あつい → 暑あつければ
  • 安やすい → 安やすければ
  • いい(Хорошо) →よければ(нерегулярный)

Na-прилагательные и существительные

Добавлятьなら (ば)илиであれば.

  • 暇ひま → 暇ひまならば
  • 学生がくせい → 学生がくせいならば

3. Отрицательные глаголы

Чтобы сказать «если [один] не...», замените～いпринадлежащийНай-формас～ければ.

  • 行いかない →行いかなければ(Если я не пойду)
  • 食たべない →食たべなければ(Если я не поем)
