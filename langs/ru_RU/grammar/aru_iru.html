Существование:あるиいる

В японском языке есть два глагола, которые означают «быть» или «существовать». Тот, который вы используете, зависит от того, является ли объект «живым» или «неживым».

1.ある(Неживые существа)

Используйте `ある` для неодушевленных предметов, растений или абстрактных понятий (идей, событий).

  • 本ほんが`あります`。
    (Есть книга.)
  • 明日あした、テストが`あります`。
    (Завтра тест.)
  • 花はなが`あります`。
    (Есть цветок.)

2.いる(Живые существа)

Используйте `いる` для людей и животных (вещей, которые движутся по своей воле).

  • 猫ねこが`います`。
    (Есть кот.)
  • 学生がくせいが`います`。
    (Есть студент.)
  • 友達ともだちが`います`。
    (У меня есть друг/Есть друг.)

3. Структура предложения

Чтобы сказать «где» что-то находится, используйте частицу «に» для обозначения местоположения.

`[Местоположение] に [Тема] が あります/います。`

  • 机つくえの上うえに本ほんが`あります`。
    (На столе лежит книга.)
  • 庭にわに犬いぬが`います`。
    (В саду есть собака.)

4. Краткое описание

Глагол Тип предмета Примеры
`ある` неодушевленный Ключи, Автомобиль, Вечеринка, Дерево
`いる` Оживить Человек, Собака, Рыба, Учитель
