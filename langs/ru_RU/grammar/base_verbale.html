Основа глагола (連用形れんようけい)

The Основа глагола(также называемыйМасу-стебельилиБаза 2) является наиболее фундаментальным строительным блоком японского спряжения. Зная основу, вы сможете присоединять десятки разных окончаний, чтобы изменить значение глагола.

1. Как сформировать стебель

Группа 1: У-глаголы (Годан)

Изменить финал"ты"звук словарной формы к соответствующему"я"звук.

  • 買かう → 買かい
  • 聞きく → 聞きき
  • 話はなす → 話はなし
  • 遊あそぶ → 遊あそび

Группа 2: Ру-глаголы (Ичидан)

Просто удалите финалる.

  • 食たべる → 食たべ
  • 見みる → 見み
  • 寝ねる → 寝ね

Группа 3: Неправильные глаголы

Запомните эти два:

  • する →し
  • 来くる (куру) →来き(ки)

2. Почему важен стебель?

Стебель используется для создания многих распространенных форм. Вот несколько примеров, которые вы узнаете:

  • Основа + ます:Вежливая форма(行いきます)
  • Основа + たい:Выражение желания (行いきたい)
  • Основа + ながら:Одновременные действия (歩あるきながら)
  • Основа + すぎる:Делаю слишком много(食たべすぎる)
  • Основа + なさい:Отдаю заказ(飲のみなさい)

3. Формальное использование

В формальном письме основа может использоваться сама по себе для соединения двух предложений, подобно тому, какТе-форма.
