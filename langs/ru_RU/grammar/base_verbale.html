Основа глагола (連用形れんようけい)

«Стержень глагола» (также называемый «основа-масу» или «основа 2») является наиболее фундаментальным строительным блоком японского спряжения. Зная основу, вы сможете присоединять десятки разных окончаний, чтобы изменить значение глагола.

1. Как сформировать стебель

Группа 1: У-глаголы (Годан)

Измените последний звук «u» в словарной форме на соответствующий звук «i».

  • 買か`う` →買か`い`
  • 聞き`く` →聞き`き`
  • 話はな`す` →話はな`し`
  • 遊あそ`ぶ` →遊あそ`び`

Группа 2: Ру-глаголы (Ичидан)

Просто удалите последнее `る`.

  • 食たべ`る` →食た`べ`
  • 見み`る` →見み
  • 寝ね`る` →寝ね

Группа 3: Неправильные глаголы

Запомните эти два:

  • する → `し`
  • 来くる (куру) → `来き` (ки)

2. Почему важен стебель?

Стебель используется для создания многих распространенных форм. Вот несколько примеров, которые вы узнаете:

  • `Стержень + ます:` Вежливая форма (行いきます)
  • `Stem + たい:` Выражение желания (行いきたい)
  • `Stem + ながら:` Одновременные действия (歩あるきながら)
  • `Stem + すぎる:` Делать слишком много (食たべすぎる)
  • `Stem + なさい:` Отдать приказ (飲のみなさい)

3. Формальное использование

В формальном письме основа может использоваться сама по себе для соединения двух предложений, подобно «Те-форме».
