Siguiendo instrucciones: ～とおりに y ～どおりに

La expresión `～とおりに` se usa para decir que una acción se realiza exactamente como otra cosa indica: seguir un camino, un conjunto de instrucciones o un pensamiento. Se traduce como "exactamente como...", "siguiendo..." o "según...".

1. Estructura de la oración

La conexión depende de si usas un verbo o un sustantivo.

Con verbos (diccionario o forma Ta)

  • 私わたしが言いった`とおりに`してください.
    (Por favor, haga "exactamente lo" que le dije).
  • 説明書せつめいしょに書かいてある`とおりに`、組くみ立たてました。
    (Lo monté "exactamente como" está escrito en el manual).

con sustantivos

Puedes usar `Noun + の + とおり` o la versión sonora `Noun + どおり` (sin la partícula `の`).

  • 地図ちず`の と り に`行いけば、着つきます。
    (Si vas `según` el mapa, llegarás).
  • 計画けいかく`ど お り に`進すすんでいます。
    (Está procediendo "según" el plan.)

2. Tabla de conexiones

Tipo Conexión
Verbos Forma simple + `とおりに`
Sustantivos (Método 1) Sustantivo + `の` + `とおりに`
Sustantivos (Método 2) Sustantivo + `どおりに`

3. Expresiones comunes

  • 思おもったとおり (Exactamente como pensé)
  • 期待きたいどおり (Como se esperaba)
  • 命令めいれいどおり (Según lo ordenado)
