La raíz del verbo (連用形れんようけい)

La "Raíz verbal" (también llamada "Raíz Masu" o "Base 2") es el componente más fundamental de la conjugación japonesa. Una vez que conozca la raíz, puede adjuntar docenas de terminaciones diferentes para cambiar el significado del verbo.

1. Cómo formar el tallo

Grupo 1: Verbos U (Godan)

Cambie el sonido final `"u"` de la forma del diccionario al sonido `"i"` correspondiente.

  • 買か`う` →買か`い`
  • 聞き`く` →聞き`き`
  • 話はな`す` →話はな`し`
  • 遊あそ`ぶ` →遊あそ`び`

Grupo 2: Ru-Verbos (Ichidan)

Simplemente elimine el `る` final.

  • 食たべ`る` →食た`べ`
  • 見み`る` →見み
  • 寝ね`る` →寝ね

Grupo 3: Verbos irregulares

Memoriza estos dos:

  • する → `し`
  • 来くる (kuru) → `来き`(ki)

2. ¿Por qué es importante el Tallo?

El tallo se utiliza para crear muchas formas comunes. Aquí hay algunos ejemplos que aprenderá:

  • `Tabla + ます:` Forma educada (行いきます)
  • `Raíz + たい:` Expresando deseo (行いきたい)
  • `Stem + ながら:` Acciones simultáneas (歩あるきながら)
  • `Stem + すぎる:` Haciendo demasiado (食たべすぎる)
  • `Stem + なさい:` Dando una orden (飲のみなさい)

3. Uso formal

En la escritura formal, la raíz se puede utilizar por sí sola para conectar dos oraciones, de forma muy parecida a la "forma Te".
