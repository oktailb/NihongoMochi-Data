La partícula や ("Y" no exhaustivo)

La partícula `や` se usa para enumerar sustantivos cuando quieres dar a entender que hay otras cosas en el grupo además de las que mencionaste. Se traduce como "A, B, etcétera".

1. Estructura de la oración

Coloque `や` entre los sustantivos. A menudo se usa con `など` al final de la lista.

  • 机つくえの上うえに本ほん`や`ペンがあります.
    (Hay libros, bolígrafos [entre otras cosas] sobre el escritorio).
  • スーパーで肉にく`や`野菜やさいを買かいました。
    (Compré carne, verduras, etc. en el supermercado).

2. Diferencia de と

  • `と:` Se usa para una lista completa (A y B, eso es todo).
  • `や:` Se utiliza para una lista incompleta (A, B y otras).

3. Uso con など

Es muy común ver `や` y `など` emparejados para mostrar claramente que la lista son solo algunos ejemplos.

  • かばんの中に財布さいふ`や`鍵かぎ`など`が入っています.
    (Hay cosas como una billetera y llaves en el bolso).
