Mientras / Dentro de límites: ～かぎり

la expresión~ か ぎ り(escrito como～限り) se utiliza para establecer una condición o un límite. Se traduce como "mientras...", "mientras un estado continúe...", o "en la medida de..."

1. Mientras (Condición)

Utilice esto para expresar que un determinado resultado continuará mientras la situación actual permanezca sin cambios.

  • 体からだが丈夫じょうぶなかぎり、働はたらきつづけたい。
    (Mientrasmi cuerpo está sano, quiero seguir trabajando.)
  • この契約けいやくを守まもるかぎり、問題もんだいはありません。
    (MientrasSi sigues este contrato, no hay problemas.)

2. Dentro de los límites de (Extensión)

Utilice esto para enfatizar que está haciendo todo lo posible dentro de su poder o conocimiento.

  • 力ちからのかぎり、頑張がんばります。
    (Haré lo mejor que puedaen la medida demi poder.)
  • 私の知しっているかぎりでは、かれは犯人はんにんではありません。
    (HastaLo sé, él no es el criminal.)
