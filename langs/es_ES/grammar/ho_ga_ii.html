Dar consejos: ～ほうがいい

Para dar consejos o sugerencias, el japonés utiliza la estructura～ほうがいい. Dependiendo de si sugieres hacer o evitar algo, la forma verbal cambia.

1. Sugerir una acción (afirmativa)

Utilice elTiempo pasado (forma Ta). Aunque estés dando consejos para el futuro, la forma Ta se utiliza para expresar que la elección "ya está decidida" como la mejor.

[Verboた形たけい] + ほうがいいです

  • 薬くすりを飲のんだほうがいいです。
    (Deberías tomar medicamentos. / Es mejor tomar medicamentos).
  • もっと早はやく寝ねたほうがいいですよ。
    (Sería mejor acostarse más temprano, ¿sabes?)

2. Sugerir evitación (negativo)

Utilice elForma negativa (forma Nai).

[Verboない形ないけい] + ほうがいいです

  • お酒さけを飲のまないほうがいいです。
    (No debes beber alcohol. / Es mejor no beber).
  • そんなに心配しんぱいしないほうがいいですよ。
    (Será mejor que no te preocupes tanto).

3. Nota de matices

Esta expresión puede sonar bastante fuerte o directa. Cuando se habla con un superior, suele ser mejor utilizar una expresión más suave como～たらどうですか(¿Qué tal...?).
