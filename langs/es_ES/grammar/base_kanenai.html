Riesgo de: ～かねない

El sufijo `～かねない` se utiliza para expresar que existe la posibilidad o el riesgo de que se produzca un "resultado negativo". Se traduce como "podría suceder", "posiblemente..." o "existe el riesgo de que..."

1. Estructura de la oración

Adjunte `かねない` a la `Raíz verbal` (la parte antes de `~ます`).

`[Raíz verbal] + かねない`

  • そんなにスピードを出だすと、事故じこを起おこし`かねない`.
    (Si acelera así, "posiblemente" podría causar un accidente).
  • あまり無理むりをすると、病気びょうきになり`かねません`よ.
    (Si trabaja demasiado, corre el riesgo de enfermarse).
  • うっかりしていると、秘密ひみつを漏もらし`かねない`.
    (Si es descuidado, es posible que filtre el secreto).

2. Matiz clave: predicción negativa

A diferencia de `～かもしれない` (que es neutral), `～かねない` se usa casi exclusivamente para situaciones indeseables. Implica que si el comportamiento actual continúa, es probable que se produzca un desastre o un error.

3. Ejemplo de conexión

Verbo Provenir "Riesgo de..."
起おこす 起おこし 起おこしかねない
なる なり なりかねない
