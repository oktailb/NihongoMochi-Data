Excepto y más allá: ～以外 (いがい)

Cuando desea excluir algo de un grupo o hablar de cosas "además de" un elemento específico, usamos `～以外 (いがい)`. Es esencial para definir límites y excepciones.

1. Estructura de la oración

  • `Sustantivo` + 以外 (の + Sustantivo)
  • `Verbo (forma simple)` + 以外

2. Definición de ejemplos

  • 彼かれ`以外`はみんな来くました。
    (Todos vinieron menos él.)
  • この仕事しごと`以外`に何なにかできることはありますか？
    (¿Hay algo más que pueda hacer además de este trabajo?)
  • 勉強べんきょうする`以外`に方法ほうほうはない。
    (No hay otra manera que estudiar).

3. La nota del sensei

`以外` es muy preciso. Si quieres decir "Además de X, también está Y", puedes usar `ほか　に`. Pero si quieres dibujar estrictamente un círculo alrededor de X y decir "todo lo que está fuera de este círculo", `以外` es tu mejor herramienta.
