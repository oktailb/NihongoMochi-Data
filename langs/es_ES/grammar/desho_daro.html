Probabilidad: ～でしょう y ～だろう

Estas expresiones se utilizan para expresar una suposición o probabilidad sobre algo. Significan "probablemente", "creo" o "¿verdad?".

1. La diferencia

  • `～でしょう:` Forma educada. Se utiliza en situaciones formales, pronósticos del tiempo o cuando se es cortés con los demás.
  • `～だろう:` Forma casual. Usado con amigos, familiares o por hombres de una manera un poco más brusca.

2. Uso básico (adivinanzas)

Adjunte directamente a la "forma simple" de verbos y adjetivos. Para sustantivos y adjetivos na, no agregue `だ`.

  • 明日あしたは晴はれる`でしょう`.
    (Mañana probablemente hará sol).
  • この料理りょうりはおいしい`だろう`.
    (Esta comida probablemente sea deliciosa).
  • 田中たなかさんは暇ひま`だろう`。
    (El Sr. Tanaka probablemente esté libre).

3. Buscando confirmación (¿verdad?)

Cuando se dice con una entonación ascendente, funciona como una pregunta de etiqueta ("...¿verdad?").

  • 明日あした、行いく`でしょう`？
    (Irás mañana, ¿verdad?)

4. Resumen de conexión

Tipo Conexión
Verbos / い-Adj Forma simple + でしょう/だろう
な-Adj / Sustantivos Palabra (sin `だ`) + でしょう/だろう
