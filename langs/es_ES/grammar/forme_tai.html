Expresando deseo: ～たい

La forma `～たい` se utiliza para expresar lo que `quieres hacer`. Se utiliza principalmente para sus propios deseos o para preguntarle a alguien directamente sobre los suyos.

1. Cómo conjugar

La terminación `～たい` se adjunta a la `Raíz verbal` (la misma parte utilizada para laますforma).

Grupo 1: Verbos U (Godan)

Cambie el sonido final `"u"` a `"i"` y agregue `たい`.

  • 行いく →行いき + たい = `行いきたい` (Quiero ir)
  • 飲のむ →飲のみ + たい = `飲のみたい` (Quiero beber)
  • 話はなす →話はなし + たい = `話はなしたい` (Quiero hablar)

Grupo 2: Ru-Verbos (Ichidan)

Elimine `る` y agregue `たい`.

  • 食たべる → `食たべたい` (Quiero comer)
  • 見みる → `見みたい` (Quiero ver)

Grupo 3: Verbos irregulares

  • する → `したい`
  • 来くる → `来きたい`

2. Conjugación (como un adjetivo I)

Una vez que un verbo está en la forma `～たい`, se conjuga exactamente como un `adjetivo I`.

Forma Final Ejemplo (行いきたい)
Presente afirmativo ～たい 行いきたいです
Presente negativo ～`たくない` 行いたくないです
Pasado afirmativo ～`たかった` 行いたかったです
Pasado negativo ～`たくなかった` 行いたくなかったです

3. Partículas con ～たい

Cuando se usa `～たい`, el objeto se puede marcar con `を` o `が`. El uso de `が` a menudo enfatiza el objeto del deseo.

  • 水みず`を`飲のみたい。
    (Quiero beber agua).
  • 水みず`が`飲のいたい。
    (Quiero beber "agua".)
