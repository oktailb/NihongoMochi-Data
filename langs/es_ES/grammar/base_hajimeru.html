Para empezar: ～はじめる

El sufijo `～はじめる` (escrito como `～始める`) se utiliza para expresar que se ha iniciado una acción o un proceso. A diferencia de `～だす`, se utiliza para inicios intencionales o naturales.

1. Estructura de la oración

Adjunte `はじめる` a la `Raíz verbal` (la parte antes de `~ます`).

`[Raíz verbal] + はじめる`

  • 日本語にほんごを`勉強べんきょうしはじめました`.
    (Empecé a estudiar japonés).
  • 雨あめが`降ふりはじめました`.
    (Empezó a llover.)
  • 本ほんを`読よみはじめましょう`.
    (Comencemos a leer el libro).

2. Conjugación

Una vez que se adjunta `はじめる`, se comporta como un verbo del Grupo 2 (Ichidan).

  • `Cortés:` ～しはじめます
  • `Pasado:` ～しはじめました
  • `Negativo:` ～しはじめない
