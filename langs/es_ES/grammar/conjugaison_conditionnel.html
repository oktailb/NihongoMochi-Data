Conjugación condicional (仮定形かていけい)

El～ばLa forma se utiliza para crear oraciones condicionales (si...). Dominar su formación es esencial para patrones gramaticales avanzados como "cuanto más... más...".

1. Verbos

Grupo 1: Verbos U (Godan)

cambiar la final"tú"sonido al correspondiente"mi"sonar y agregarば.

  • 行いく → 行いけば
  • 話はなす → 話はなせば
  • 飲のむ → 飲のめば

Grupo 2: Ru-Verbos (Ichidan)

Reemplazar el finalるconれば.

  • 食たべる → 食たべれば
  • 見みる → 見れば

Grupo 3: Verbos irregulares

  • する →すれば
  • 来くる →来くれば(pronunciadokureba)

2. Adjetivos

I-Adjetivos

Reemplazar el final～いcon～ければ.

  • 暑あつい → 暑あつければ
  • 安やすい → 安やすければ
  • いい(Bien) →よければ(Irregular)

Na-Adjetivos y sustantivos

Agregarなら (ば)oであれば.

  • 暇ひま → 暇ひまならば
  • 学生がくせい → 学生がくせいならば

3. Verbos negativos

Para decir "si [uno] no...", reemplace la～いdelforma naicon～ければ.

  • 行いかない →行いかなければ(Si no voy)
  • 食たべない →食たべなければ(Si no como)
