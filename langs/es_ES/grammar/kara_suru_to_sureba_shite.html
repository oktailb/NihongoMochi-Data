A juzgar por: ～からすると / ～からすれば / ～からして

La expresión `～からすると` (y sus variantes `～からすれば` o `～からして`) se utiliza para llegar a un juicio o conclusión basada en un punto de vista, evidencia o pista específica. Se traduce como "a juzgar por...", "considerando..." o "basado en..."

1. Estructura de la oración

Adjunte estas expresiones directamente a un "sustantivo".

`[Sustantivo] + からすると / からすれば / からして`

  • かれの性格せいかく`からすると`、そんなことは言いわないだろう。
    (A juzgar por su personalidad, probablemente no diría tal cosa).
  • この足音あしおと`からすると`、お父とうさんが帰かえってきたようだ。
    (A juzgar por estos pasos, parece que mi padre ha regresado).
  • このレストランは、外観がいかん`からして`高たかそうだ。
    (A juzgar por el exterior, este restaurante parece caro).

2. Uso clave: pistas específicas

`～からして` se utiliza a menudo para seleccionar una sola característica (como la apariencia o una primera impresión) para representar por qué se hace el juicio general.

3. Distinción de ～によると

  • `～によると:` Se usa para citar una fuente de información (Según la noticia...).
  • `～からすると:` Se utiliza para expresar un `juicio o conjetura personal` basado en pistas.
