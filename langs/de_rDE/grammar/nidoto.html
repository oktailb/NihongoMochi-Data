Nie wieder: 二度と (にどと)

Wenn Sie eine feste Entscheidung getroffen haben oder etwas so Schreckliches erlebt haben, dass es nie wieder passieren soll, verwenden wir二度と (にどと). Es wird immer mit einem negativen Verb gepaart, um „nie wieder“ auszudrücken.

1. Satzstruktur

二度と+ Verb (Negativform)

2. Firmenbeispiele

  • あんな所ところへは二度と行いかない。
    (Ich werde nie wieder an einen solchen Ort gehen!)
  • 二度と嘘うそをつかないと約束やくそくします.
    (Ich verspreche, dass ich nie wieder lügen werde.)
  • こんな失敗しっぱいは二度と起おこしたくない。
    (Ich möchte nie wieder einen solchen Fehler machen.)

3. Senseis Notiz

Dieses Wort ist sehr kraftvoll. Verwenden Sie es, wenn Sie Ihren eisernen Willen oder eine sehr starke emotionale Grenze zeigen möchten. Wenn Sie nur „nicht oft“ meinen, verwenden SieAmari Nai. 二度とist für die lebensverändernden „Nie wieder“-Momente!
