Vollständig beenden: ～きれる / ～きれない

Das Suffix～きる(vollständig beenden) wird~きれるin seiner potentiellen Form. Damit wird ausgedrückt, dass eine Handlung aufgrund ihres Umfangs oder ihrer Schwierigkeit bis zum Ende beendet werden kann oder nicht.

1. Satzstruktur

BefestigenきれるoderきれないzumVerbstamm.

  • こんなにたくさんの料理りょうりは、一人ひとりでは食たべきれません。
    (Ich kann das ganze Essen nicht alleine aufessen.)
  • かれは一晩ひとばんでその本ほんを読よみきった。
    (Er hat das ganze Buch an einem Abend zu Ende gelesen.)
  • 数かずえきれないほどたくさんの星ほしが見みえます.
    (Ich kann so viele Sterne sehen, dass sie unzählbar sind [kann das Zählen nicht beenden].)
