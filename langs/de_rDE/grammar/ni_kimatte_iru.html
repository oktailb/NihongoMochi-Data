Offensichtliche Gewissheit: に決まっている

Wenn etwas so offensichtlich ist, dass kein Zweifel besteht, verwenden wir～に決まっている. Es drückt die starke Überzeugung des Sprechers aus, dass etwas wahr sein muss. Es ist, als würde man „Natürlich!“ sagen. oder „Das wird bestimmt...!“

1. Satzstruktur

[Verb/Adj/Substantiv in einfacher Form] + に決まっている

2. Sichere Beispiele

  • そんなの、嘘うそに決まっている！
    (Das ist bestimmt eine Lüge! / Natürlich ist das eine Lüge!)
  • 一生懸命いっしょうけんめい練習れんしゅうしたんだから、勝かつに決まっている。
    (Da wir so hart trainiert haben, werden wir bestimmt gewinnen.)
  • そんなことをしたら、怒おこられるに決まっている。
    (Wenn Sie so etwas tun, werden Sie bestimmt beschimpft.)

3. Senseis Notiz

Dies ist eine subjektive, aber sehr starke Aussage. Es zeigt, dass Sie sich aufgrund Ihrer eigenen Logik oder Gefühle zu 100 % sicher sind. In lockerer Sprache wird es oft so～にきまってる. Verwenden Sie es, wenn Ihnen die Schlussfolgerung vernünftig vorkommt!
