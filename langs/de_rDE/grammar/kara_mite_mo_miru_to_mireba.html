Aus der Sicht von: ～から見ても / ～から見ると / ～から見れば

Der Ausdruckから見ると(und seine Varianten～から見ればoder～から見ても) wird verwendet, um ein Urteil oder eine Beobachtung aus einer bestimmten Perspektive oder einem bestimmten Standpunkt auszudrücken. Übersetzt bedeutet es „vom Standpunkt aus gesehen“, „von … aus gesehen“ oder „betrachtet …“.

1. Satzstruktur

Hängen Sie diese Ausdrücke direkt an a anSubstantiv(eine Person, eine Gruppe oder ein abstraktes Konzept).

[Nomen] + から見ると / から見れば / から見ても

  • 教師きょうしから見れば、 かれはとてもまじめな学生がくせいです.
    (Aus der Sicht eines Lehrers ist er ein sehr ernsthafter Schüler.)
  • 外国人がいこくじんから見ると、日本にほんの物価ぶっかは高たかいと感かんじるかもしれない.
    (Aus der Sicht eines Außenstehenden [Ausländers] könnten sie das Gefühl haben, dass die Preise in Japan hoch sind.)
  • かれの実力じつりょくから見れば、 こ の テ ス ト は簡単かんたんすぎるはずだ.
    (Aus der Sicht seiner tatsächlichen Fähigkeiten dürfte dieser Test zu einfach sein.)

2. Schlüsselnuance: Beobachtung basierend auf der Position

Im Gegensatz zu~ni shitara(Empathie),から見るとkonzentriert sich auf dieobjektive Beobachtungaus einer bestimmten Position oder Kategorie erstellt.

3. Unterscheidung von ～からすると

  • からすると:Betont dieBeweise oder Hinweiseverwendet, um eine Vermutung anzustellen.
  • から見ると:Betont dieStandpunkt oder Winkelvon dem aus man etwas betrachtet.
