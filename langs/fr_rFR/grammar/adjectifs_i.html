I-Adjectifs (い形容詞いけいようし)

En japonais, les adjectifs sont divisés en deux groupes.I-adjectifssont uniques car ils peuvent être conjugués tout comme les verbes pour indiquer le temps (passé, négatif, etc.).

1. Identifier les I-Adjectifs

Tous les adjectifs I se terminent par l'hiraganaい. (Remarque : quelques adjectifs Na comme きれい se terminent également par « i », alors soyez prudent !)

  • 大おおきい (Grand)
  • 小ちいさい (Petit)
  • 高たかい (Cher / Grand)
  • 暑あつい (Chaud)
  • おいしい (Délicieux)

2. Règles de conjugaison

Pour changer le temps, supprimez le finalいet ajoutez les terminaisons suivantes :

Tendu Fin Exemple (高たかい)
Présent Affirmatif ～い 高たかい (C'est cher)
Présent négatif ～くない 高たかくない (Ce n'est pas cher)
Passé Affirmatif ～かった 高たかかった (C'était cher)
Passé négatif ～くなかった 高たかくなかった (Ce n'était pas cher)

3. Le cas particulier :いい(Bien)

Le mot pour « bien » est irrégulier. Ses conjugaisons sont basées sur sa forme originale :良よい.

  • Présent Affirmatif :いい
  • Présent Négatif :良よくない
  • Passé Affirmatif :良よかった
  • Passé négatif :良よくなかった

4. Utilisation

Vous pouvez les utiliser directement avant un nom ou à la fin d'une phrase.

  • 高たかい車くるま
    (Une voiture chère)
  • この車くるまは高たかいです。
    (Cette voiture est chère.)
