La Particule と (Et/Avec)

La particuleとa deux fonctions principales : relier les noms dans une liste complète et indiquer la personne avec laquelle vous effectuez une action.

1. Noms de connexion (exhaustif "Et")

Utiliserとentre les noms pour tout lister. Cela implique que la liste est complète.

  • 机つくえ·上うえに本ほんとペンがあります。
    (Il y a un livreetun stylo sur le bureau [et rien d'autre].)
  • パンと卵たまごを食たべました。
    (j'ai mangé du painetun œuf.)

2. Faire ensemble (Avec)

Utiliserとaprès une personne pour montrer que vous faites une action avec elle.

  • 友達ともだちと映画えいがを見みに行きました。
    (je suis allé voir un filmavecun ami.)
  • 家族かぞくと住すんでいます。
    (Je visavecma famille.)

3. Marqueur de citation

Il est également utilisé pour marquer une citation directe ou indirecte avant des verbes comme言いう (dire) ou思おもう (penser).

  • 田中さんは「暑あつい」と言いいました。
    (M. Tanaka a dit "il fait chaud".)
