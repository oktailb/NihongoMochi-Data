Después de hacer: ～あとで

Para decir "después de hacer algo" o "después de cierto evento", el japonés usa~ あ と で. Es lo opuesto a~前まえに.

1. Usar con verbos

Utilice elTiempo pasado (forma Ta)del verbo. Esto se debe a que la acción debe completarse antes de que comience la siguiente.

[Verboた形たけい] + あとで

  • 仕事しごとが終おわったあとで、飲のみに行いきます。
    (Cuando termine el trabajo, iré a tomar una copa).
  • 映画えいがを見みたあとで、 カ フ ェ に行いきました。
    (Después de ver la película, fui a un café).

2. Usar con sustantivos

Cuando uses un sustantivo (un evento), conéctalo usando la partículaの.

[Sustantivo] + の + あとで

  • 授業じゅぎょうのあとで、先生せんせいに質問しつもんしました。
    (Después de clase, le hice una pregunta al profesor).
  • テ ス トのあとで、アイスクリームを食たべました。
    (Después de la prueba, comí helado).

3. Comparación: ～てから

Una estructura similar es～てから. Mientrasあとでsimplemente marca la secuencia de eventos,てからDestaca que la primera acción es un requisito previo para la segunda.

  • 手てを洗あらってから、食たべます。
    (Después de lavarme [y porque me lavé] las manos, como).
