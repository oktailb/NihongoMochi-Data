Siguiendo instrucciones: ～とおりに y ～どおりに

la expresión~ と り にSe utiliza para decir que una acción se realiza exactamente como otra cosa indica: seguir un camino, un conjunto de instrucciones o un pensamiento. Se traduce como "exactamente como...", "siguiendo..." o "según...".

1. Estructura de la oración

La conexión depende de si usas un verbo o un sustantivo.

Con verbos (diccionario o forma Ta)

  • 私わたしが言いったと お り にしてください。
    (Por favor hazloexactamente comoYo dije.)
  • 説明書せつめいしょに書かいてあると お り に、組くみ立たてました。
    (lo montéexactamente comoescrito en el manual.)

con sustantivos

puedes usarSustantivo + の + とおりo la versión sonoraSustantivo + どおり(sin la partículaNo).

  • 地図ちずの と り に行いけば、着つきます。
    (Si vasde acuerdo ael mapa, llegarás.)
  • 計画けいかくど お り に進すすんでいます。
    (Está procediendode acuerdo aplan.)

3. Expresiones comunes

  • 思おもったとおり (Exactamente como pensé)
  • 期待きたいどおり (Como se esperaba)
  • 命令めいれいどおり (Según lo ordenado)
