Para empezar: ～はじめる

el sufijo～はじめる(escrito como～始める) se utiliza para expresar que una acción o un proceso ha comenzado. A diferencia de～だす, se utiliza para arranques intencionales o naturales.

1. Estructura de la oración

Adjuntarはじめるhaciaraíz verbal(la parte anterior~masu).

[Raíz verbal] + はじめる

  • 日本語にほんごを勉強べんきょうしはじめました。
    (Empecé a estudiar japonés).
  • 雨あめが降ふりはじめました。
    (Empezó a llover.)
  • 本ほんを読よみはじめましょう。
    (Comencemos a leer el libro).

2. Conjugación

Una vezはじめるestá adjunto, se comporta como un verbo del Grupo 2 (Ichidan).

  • Educado:～しはじめます
  • Pasado:～しはじめました
  • Negativo:～しはじめない
