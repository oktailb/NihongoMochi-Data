La raíz del verbo (連用形れんようけい)

Elraíz verbal(también llamado eltallo masuoBase 2) es el componente más fundamental de la conjugación japonesa. Una vez que conozca la raíz, puede adjuntar docenas de terminaciones diferentes para cambiar el significado del verbo.

1. Cómo formar el tallo

Grupo 1: Verbos U (Godan)

cambiar la final"tú"sonido de la forma del diccionario al correspondiente"i"sonido.

  • 買かう → 買かい
  • 聞きく → 聞きき
  • 話はなす → 話はなし
  • 遊あそぶ → 遊あそび

Grupo 2: Ru-Verbos (Ichidan)

Simplemente retire la finalる.

  • 食たべる → 食たべ
  • 見みる → 見み
  • 寝ねる → 寝ね

Grupo 3: Verbos irregulares

Memoriza estos dos:

  • する →し
  • 来くる (kuru) →来き(ki)

2. ¿Por qué es importante el Tallo?

El tallo se utiliza para crear muchas formas comunes. Aquí hay algunos ejemplos que aprenderá:

  • Tallo + ます:Forma educada (行いきます)
  • Tallo + たい:Expresar deseo (行いきたい)
  • Tallo + ながら:Acciones simultáneas (歩あるきながら)
  • Tallo + すぎる:haciendo demasiado (食たべすぎる)
  • Tallo + なさい:Dando una orden (飲のみなさい)

3. Uso formal

En la escritura formal, la raíz se puede usar por sí sola para conectar dos oraciones, de manera muy similar a laTe-forma.
