La partícula や ("Y" no exhaustivo)

la partículaやse usa para enumerar sustantivos cuando quieres dar a entender que hay otras cosas en el grupo además de las que mencionaste. Se traduce como "A, B, etcétera".

1. Estructura de la oración

Lugarやentre sustantivos. A menudo se utiliza conなどal final de la lista.

  • 机つくえの上うえに本ほんやペンがあります。
    (Hay libros, bolígrafos [entre otras cosas] sobre el escritorio).
  • スーパーで肉にくや野菜やさいを買かいました。
    (Compré carne, verduras, etc. en el supermercado).

2. Diferencia de と

  • と:Se utiliza para una lista completa (A y B, eso es todo).
  • や:Se utiliza para una lista incompleta (A, B y otras).

3. Uso con など

Es muy común verやyなどemparejados para mostrar claramente la lista son solo algunos ejemplos.

  • かばんの中に財布さいふや鍵かぎなどが入っています.
    (Hay cosas como una billetera y llaves en el bolso).
