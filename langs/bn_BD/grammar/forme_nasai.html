আদেশ প্রদান: ～なさい

`～なさい` ফর্মটি একটি দৃঢ় আদেশ বা নির্দেশ দিতে ব্যবহৃত হয়। যদিও এটি ব্যাকরণগতভাবে ভদ্র (সম্মানসূচক `なさる` থেকে উদ্ভূত), এটি কর্তৃত্বের একটি শক্তিশালী স্বর বহন করে। এটি সাধারণত বাবা-মায়ের দ্বারা শিশুদের জন্য, শিক্ষকদের দ্বারা ছাত্রদের কাছে বা লিখিত পরীক্ষার নির্দেশাবলীতে ব্যবহৃত হয়।

1. কিভাবে কনজুগেট করবেন

`なさい` সরাসরি `ক্রিয়া স্টেম` এর সাথে সংযুক্ত করুন (`~ます` এর আগের অংশ)।

`[ক্রিয়া কান্ড] + なさい`

  • 食たべます →食たべ + なさい = `食たべなさい` (খাও!)
  • 行いきます →行いき + なさい = `行いきなさい` (যাও!)
  • します → し + なさい = `しなさい` (এটি করুন!)

2. মূল উদাহরণ

  • 「もう遅おそいから、早はやく`寝ねなさい'।''
    ("ইতিমধ্যেই দেরি হয়ে গেছে, তাই তাড়াতাড়ি ঘুমাতে যান।")
  • 「テレビを消けして,宿題しゅくだいを`しなさい'।''
    ("টিভি বন্ধ করুন এবং আপনার বাড়ির কাজটি করুন।")
  • 「つぎの質問しつもんに`答こたえなさい'।''
    ("'উত্তর' নিচের প্রশ্নের।")

3. Nuance: কখন এটি ব্যবহার করবেন না

কারণ `～なさい` একটি স্পষ্ট শ্রেণিবিন্যাস বোঝায় যেখানে শ্রোতার উপর বক্তার কর্তৃত্ব আছে, আপনি এটিকে 'কখনই' একজন উচ্চতর (বস, শিক্ষক) বা অপরিচিত ব্যক্তির দিকে ব্যবহার করবেন না। এই ক্ষেত্রে, অনুরোধের জন্য `～てください` ব্যবহার করুন।

4. দ্রুত পরামর্শ: ～なさい বনাম ～ろ (জরুরী)

  • `～なさい:` দৃঢ় এবং কর্তৃত্বপূর্ণ, কিন্তু একটি "সংশোধনমূলক" বা শিক্ষাগত উপায়ে ব্যবহৃত হয় (পিতামাতা, শিক্ষক)।
  • `～ろ (প্রয়োজনীয় ফর্ম):` খুব রুক্ষ, আক্রমনাত্মক, বা জরুরী পরিস্থিতিতে ব্যবহৃত। এটা `~なさい` এর চেয়ে অনেক বেশি কঠোর শোনাচ্ছে৷
