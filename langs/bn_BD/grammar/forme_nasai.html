আদেশ প্রদান: ～なさい

দ～なさいফর্ম একটি দৃঢ় আদেশ বা নির্দেশ দিতে ব্যবহৃত হয়. যদিও এটি ব্যাকরণগতভাবে ভদ্র (সম্মানসূচক থেকে উদ্ভূতনাসারু), এটি কর্তৃত্বের একটি শক্তিশালী স্বর বহন করে। এটি সাধারণত বাবা-মায়ের দ্বারা শিশুদের জন্য, শিক্ষকদের দ্বারা ছাত্রদের কাছে বা লিখিত পরীক্ষার নির্দেশাবলীতে ব্যবহৃত হয়।

1. কিভাবে কনজুগেট করবেন

সংযুক্ত করুনなさいসরাসরিক্রিয়া কান্ড(আগের অংশ~মাসু)

[ক্রিয়াপদ স্টেম] + なさい

  • 食たべます →食たべ + なさい =食たべなさい(খাও!)
  • 行いきます →行いき + なさい =行いきなさい(যাও!)
  • します → し + なさい =しなさい(এটা করো!)

2. মূল উদাহরণ

  • 「もう遅おそいから、早はやく寝ねなさい।''
    ("এটি ইতিমধ্যে দেরি হয়ে গেছে, তাইঘুমাতে যানদ্রুত।")
  • 「テレビを消けして,宿題しゅくだいをしなさい।''
    ("টিভি বন্ধ করুন এবংকরতেতোমার বাড়ির কাজ।")
  • 「つぎの質問しつもんに答こたえなさい।''
    ("উত্তরনিম্নলিখিত প্রশ্ন।")

3. Nuance: কখন এটি ব্যবহার করবেন না

কারণ～なさいএকটি স্পষ্ট শ্রেণিবিন্যাস বোঝায় যেখানে শ্রোতার উপর স্পিকারের কর্তৃত্ব রয়েছে, আপনার উচিতকখনইএটি একটি উচ্চতর (বস, শিক্ষক) বা অপরিচিত ব্যক্তির দিকে ব্যবহার করুন। এই ক্ষেত্রে, ব্যবহার করুন～てくださいঅনুরোধের জন্য

4. দ্রুত পরামর্শ: ～なさい বনাম ～ろ (জরুরী)

  • ～なさい:দৃঢ় এবং কর্তৃত্বপূর্ণ, কিন্তু একটি "সংশোধনমূলক" বা শিক্ষাগত উপায়ে ব্যবহৃত হয় (পিতামাতা, শিক্ষক)।
  • ～ろ (জরুরী ফর্ম):খুব রুক্ষ, আক্রমনাত্মক, বা জরুরী পরিস্থিতিতে ব্যবহৃত। এটার চেয়ে অনেক কঠিন শোনাচ্ছে~নাসাই.
