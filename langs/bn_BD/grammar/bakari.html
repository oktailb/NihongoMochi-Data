"শুধু" ফ্যাক্টর: ～ばかり (শুধু ঘটেছে / শুধুমাত্র)

জাপানি ভাষায়,ばかりএকটি সময় ম্যানিপুলেশন দক্ষতা মত. এটি আপনাকে প্রকাশ করতে দেয় যে "এখনই" কিছু ঘটেছে, এমনকি যদি আপনার "এখন" এর অনুভূতি কিছুটা নমনীয় হয়। এটি একটি ফিল্টার হিসাবেও কাজ করতে পারে, যার অর্থ "কিছুই নয়" বা "শুধুমাত্র।"

"I শুধু finished this boss fight!" (Even if it was 10 minutes ago, the adrenaline is still there!)

1. মোড: মাত্র সমাপ্ত (ক্রিয়াた + ばかり)

এটি ব্যবহার করুন যখন একটি কাজ আপনার মনে তাজা হয়। দুর্দান্ত জিনিসটি হল, আপনি এটি কিছুক্ষণ আগে ঘটে যাওয়া জিনিসগুলির জন্য ব্যবহার করতে পারেন, যতক্ষণ নাঅনুভব করেআপনার কাছে সাম্প্রতিক।

  • 日本にほんに来くたばかりです। (আমিশুধুজাপানে এসেছে — গতকাল বা গত সপ্তাহে হতে পারে!)
  • さっき起おきたばかりです। (আমিশুধুজেগে উঠল।)

2. মোড: কিছুই নয় কিন্তু (বিশেষ্য +ばかり)

যখন আপনি একটি লুপে আটকে থাকেন বা একই জিনিস দ্বারা বেষ্টিত হন, ব্যবহার করুনばかり"শুধু" বা "কিছুই না" বলতে।

  • 漫画まんがばかり読よんでいる. (পড়াকিছুই কিন্তুমাঙ্গা।)
  • 肉にくばかり食たべる। (খাওয়াশুধুমাত্রমাংস।)

3. "সাম্প্রতিক" দ্বন্দ্ব:ばかりবনামところ

আপনার অস্ত্র সঠিকভাবে নির্বাচন করা গুরুত্বপূর্ণ:

  • ～たところ:সুনির্দিষ্ট সময়। এটা ঘটেছেসেকেন্ডআগে ঘটনা ভিত্তিক।
  • ～たばかり:বিষয়ভিত্তিক সময়। এটা আপনি কিভাবে সম্পর্কেঅনুভব. আবেগ ভিত্তিক।

4. গ্রামার স্কিল ট্রি

ばかりএকটি বিশেষ্য মত conjugates. যদি এটি অন্য বিশেষ্য পরিবর্তন করে, ব্যবহার করুনの.

  • 買かったばかりの靴くつ(জুতা আইশুধুকেনা।)
সেনসি এর নোট: Using ばかり for "only" can sometimes sound a bit critical, like a mom scolding you for playing কিছুই কিন্তু video games. Use it wisely!

始はじめたばかりだけど、頑張がんばろう! (আমরাশুধুশুরু হয়েছে, কিন্তু আসুন আমাদের সেরাটা করি!)
