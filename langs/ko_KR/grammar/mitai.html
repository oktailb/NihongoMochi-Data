유사점 : ～ ま た い

표현~미타이다른 것과 유사하게 보이거나 동작하는 것을 설명하는 데 사용됩니다. 캐주얼 버전이에요~이런거야일상 대화에서 매우 흔하게 사용됩니다.

1. 시각적 유사성(~처럼 보인다)

본 것을 바탕으로 추측하거나, 두 가지를 비교하고 싶을 때 사용하세요.

  • 아노雲くも하에이스크림またい입니다.
    (저 구름은 아이스크림처럼 생겼어요.)
  • ㅋㅋㅋ子供こどもまたい에笑わら그렇죠.
    (그는 어린아이처럼 웃는다.)

2. 추측(그런 것 같은데...)

상황에 대한 추측을 표현하는 데에도 사용할 수 있습니다.

  • 雨あめが降ふたまたい입니다.
    (비가 내린 것 같습니다 [땅이 젖어 있습니다.]
  • 田中たなか쯧쯧쯧帰かえたまたい그렇군요.
    (다나카 씨는 이미 집에 가버린 것 같습니다.)

3. 연결

에 직접 연결됩니다.명사그리고일반 양식동사와 형용사의.

유형 연결
동사 / い-형용사 일반 양식 + たい
な-형용사 / 명사 말씀(아니요다) + 봐봐

4. 요약: 미타이 vs 라시이

  • ~미타이:시각적인 모습이나 직접적인 비교에 중점을 둡니다(X처럼 보입니다).
  • ~ しい:소문이나 일반적인 특성에 중점을 둡니다(X라고 들었습니다/X의 전형적인 특성입니다).
