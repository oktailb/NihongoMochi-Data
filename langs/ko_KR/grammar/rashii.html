추측: ～ましい

'~しい'라는 표현은 듣거나 관찰한 정보를 바탕으로 추측이나 추측을 표현하는 데 사용됩니다. 이는 "...인 것 같습니다" 또는 "그렇게 들었습니다..."로 번역됩니다.

1. 정보를 바탕으로

읽거나 들은 것 또는 간접적인 증거를 바탕으로 추측을 할 때 `~라しい`를 사용하세요.

  • 天気予報てんきよほう에루루라고、明日あしたㅋㅋㅋ雨あめ`` しい ' 입니다.
    (일기예보에 따르면 내일은 비가 올 것 같다.)
  • 田中たなか쯧쯧日本にほん에行いた`しい`입니다.
    (다나카씨가 일본에 갔다고 들었습니다.)

2. 전형적인 특성

명사와 함께 사용하면 "전형적인" 또는 "~와 같은"이라는 뜻도 됩니다.

  • 今日きょうㅋㅋㅋ春はる``라시이'天気てんき그렇군요.
    (오늘 날씨가 완전 봄같죠?)

3. 연결

동사와 형용사의 '보통형'에 직접 붙고, '명사'에는 직접 붙습니다.

유형 연결
동사 / い-형용사 일반 형태 + しい
な-형용사 / 명사 단어(`だ` 없음) + しい

4. 라시이 vs 그래서

  • `~そ우:` 직접 육안으로 관찰한 결과(검은 구름이 보입니다. 비처럼 보입니다.)
  • `~라しい:` 간접적인 증거나 소문에 기초함(비가 올 수도 있다고 뉴스에서 말함).
