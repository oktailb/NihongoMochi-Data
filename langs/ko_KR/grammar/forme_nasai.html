명령하기: ～ない

그만큼～아니요형식은 확고한 명령이나 지시를 제공하는 데 사용됩니다. 문법적으로는 예의바르지만(경어에서 파생됨)나사루), 강한 권위의 어조를 전달합니다. 일반적으로 부모가 자녀에게, 교사가 학생에게 또는 필기 시험 지침에 사용됩니다.

1. 활용방법

붙이다그렇지 않다직접동사 줄기(이전 부분~마스).

[동사 어간] + なしい

  • 食た베마스 →食た베 + 그렇지 않다 =食た베네사요(먹다!)
  • 行い키마스 →行いㅋ + ない =行い좋아요(가다!)
  • しまし → し + なしい =그렇지 않아요(해라!)

2. 주요 사례

  • 「も 」遅おそ그렇군요、早はやKU寝ね그렇지 않다。」
    ("이미 늦었으니까.자러 가다빠르게.")
  • 「테레비를」消け이라고、宿題しゅくだい을그렇지 않아요。」
    ("TV를 끄고하다숙제야.")
  • 「つぎの質問しつもん에答こた네네。」
    ("답변다음 질문입니다.")

3. 뉘앙스: 사용하지 말아야 할 경우

왜냐하면～아니요말하는 사람이 듣는 사람에 대해 권위를 갖는 명확한 계층 구조를 의미합니다.절대상사(상사, 선생님)나 낯선 사람에게 사용하세요. 그러한 경우에는 다음을 사용하십시오.～네쿠다이요요청을 위해.

4. 빠른 팁: ～なsai vs ～ろ(필수)

  • ～아니요:확고하고 권위적이지만 "교정" 또는 교육적 방법(부모, 교사)으로 사용됩니다.
  • ～ろ(명령형):매우 거칠거나 공격적이거나 긴급 상황에 사용됩니다. 생각보다 훨씬 더 심한 것 같네요~나사이.
