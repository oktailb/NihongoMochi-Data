명령하기: ～ない

～なしい 형태는 확고한 명령이나 지시를 할 때 사용됩니다. 문법적으로는 예의바르지만(존경어 'なあり'에서 파생됨) 강력한 권위의 어조를 담고 있습니다. 일반적으로 부모가 자녀에게, 교사가 학생에게 또는 필기 시험 지침에 사용됩니다.

1. 활용방법

`なsai`를 `동사 어간`(`~massu` 앞 부분)에 직접 붙입니다.

`[동사 어간] + なしい`

  • 食た베마스 →食た베 + 그렇지 = `食たべなしい` (먹어!)
  • 行い키마스 →行いㅋ + なしい = `行い키나사이`(가자!)
  • しまс → し + なsai = `しなしい` (해 보세요!)

2. 주요 사례

  • 「も 」遅おそ그렇군요、早はやKU`寝ね그렇지 않아요`。」
    (“벌써 늦었으니 빨리 `자러` 가세요.”)
  • 「테레비를」消け이라고、宿題しゅくだいを`しない`。」
    ("TV를 끄고 숙제를 해라.")
  • 「つぎの質問しつもんに`答こたえなしい`。」
    ("다음 질문에 `답`하세요.")

3. 뉘앙스: 사용하지 말아야 할 경우

`~ない`는 말하는 사람이 듣는 사람에 대해 권위를 갖는 명확한 위계를 의미하기 때문에 윗사람(상사, 선생님)이나 낯선 사람을 향해 `절대` 사용해서는 안 됩니다. 그러한 경우에는 요청 시 `~てKUだsai`를 사용하세요.

4. 빠른 팁: ～なsai vs ～ろ(필수)

  • `~なしい:` 확고하고 권위적이지만 "교정" 또는 교육적인 방법으로 사용됩니다(부모, 교사).
  • `~ろ(명령형):` 매우 거칠거나 공격적이거나 긴급 상황에 사용됩니다. ``~なしい''보다 훨씬 더 가혹하게 들립니다.
