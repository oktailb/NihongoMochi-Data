이유 제시: ～kara 및 ～の下

일본어에서는 "왜냐하면"이나 "그래서"라고 말할 때 이유를 배치합니다.~ 전에결과. 이를 표현하는 두 가지 주요 방법이 있습니다.로부터그리고の 로.

1. ～kara (주관적 이유)

로부터개인적인 이유나 의견을 표현할 때, 부탁이나 명령을 내릴 때 사용합니다.の데보다 더 주관적이고 강력합니다.

[이유] 로부터、[결과]。

  • 暑あつ있어요로부터、窓まど을開あけmas。
    (더우니까 창문을 열어두겠습니다.)
  • 時間じかん그렇지 않다로부터、急いそ정말이에요.
    (시간이 없으니 서두르자.)

2. ～のと (객관적/공손한 이유)

の 로객관적인 사실, 사회적 변명 또는 예의를 갖추기 위해 사용됩니다. 덜 강력하고 자연스러운 결과처럼 들립니다.

[이유] の데、[결과]。

  • 雨あめが降ふていりの 로、行いkiません。
    (비가 오니까 [객관적 사실] 안 가겠습니다.)
  • 用事ようじがありの 로、 あ先さき에失礼しつれい그러게요.
    (심부름이 있어서 먼저 실례하겠습니다.)

3. 연결방법

유형 (으)로부터 의로와
동사 / I-Adj 사전 형태 + 로부터 사전 양식 + の 스레
명사 / Na-Adj だ + 로부터 な+ の 에

4. 빠른 팁

사과하거나 부탁할 때는 다음을 사용하세요.の 로. 훨씬 더 부드럽고 전문적인 것 같습니다!
