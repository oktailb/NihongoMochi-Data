"Anche se": ～ても

La congiunzione `～ても` viene utilizzata per esprimere una condizione in cui qualcosa accade comunque. Si traduce in "anche se" o "anche se".

1. Struttura della frase

Collega "も" alla forma "Te" di verbi, aggettivi o sostantivi.

  • "Verbi:".雨あめが`降ふっても`、行いきます。
    (Anche se piove, andrò.)
  • `い-Agg:`高たか`くても`、買かいたいです.
    (Anche se è costoso, voglio comprarlo.)
  • `な-Agg / Sostantivi:`嫌きらい`でも`、食たべなければなりません.
    (Anche se lo odi, devi mangiarlo.)

2. Frase interrogativa comune: ～てもいいですか

Questa struttura è la base per chiedere il permesso (Posso...?).

  • 入はいってもいいですか。(Va bene se entro?)
