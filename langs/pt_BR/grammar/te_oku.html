Fazendo com antecedência: ～ておく

O verbo auxiliar `～ておく` é usado quando você executa uma ação `com antecedência` para se preparar para o futuro ou para manter um determinado estado como está.

1. Preparação para o Futuro

Fazer algo agora para não ter que se preocupar com isso mais tarde.

  • 旅行りょこうの前まえに、ホテルを`予約よやくしておきます`。
    (Vou reservar um hotel com antecedência antes da viagem.)
  • 明日あしたテストがあるから、`勉強べんきょうしておきます`。
    (Como há prova amanhã, estudarei com antecedência.)

2. Deixar um estado como está

Às vezes significa fazer algo para manter uma situação.

  • 窓まどを`開あけておいて`ください。
    (Por favor, deixe a janela aberta [mantenha-a assim].)

3. Forma casual: とく

Na linguagem casual, `～ておく` geralmente se contrai para `～とく`.

  • ～ておく → `～とく` (por exemplo,書かいとく)
  • ～でおく → `～どく` (por exemplo,飲のんどく)

`Ex:` ビール、買かいとくね！ (Vou comprar a cerveja antecipadamente! [Casual])
