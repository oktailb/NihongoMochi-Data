A forma Nai (ない形ないけい) - Negativo Informal

A `forma Nai` é usada para o presente negativo em japonês casual. É também a base para muitas estruturas gramaticais importantes, como "deve" ou "por favor, não".

1. Como conjugar

Grupo 1: Verbos U (Godan)

Mude o som final `"u"` para o som `"a"` correspondente e adicione `ない`.

  • 書かく (escrever) →書か`か`ない
  • 飲のむ (beber) →飲nom`ま`ない
  • 話はなす (falar) →話はな`さ`ない

`⚠️ Exceção:` Se o verbo terminar em `う` simples, ele muda para `わ` (não 'a').

  • 買かう (comprar) →買か`わ`ない

Grupo 2: Ru-Verbos (Ichidan)

Remova `る` e adicione `ない`.

  • 食たべる (comer) →食たべない
  • 見みる (para ver) →見みない

Grupo 3: Verbos Irregulares

  • する → `しない`
  • 来くる → `来こない`
  • ある (existir) → `ない`

2. Padrões Comuns

  1. `Pedidos para não fazer (~ないでください)`
    忘わすれないでください。
    (Por favor, não esqueça.)
  2. `Obrigação (~なければなりません)`
    勉強べんきょうしなければなりません。
    (Tenho que estudar.)
