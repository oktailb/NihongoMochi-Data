O radical verbal (連用形れんようけい)

OHaste verbal(também chamado deCaule MasuouBase 2) é o alicerce mais fundamental na conjugação japonesa. Depois de conhecer o radical, você pode anexar dezenas de terminações diferentes para alterar o significado do verbo.

1. Como formar o caule

Grupo 1: Verbos U (Godan)

Mude a final"você"som da forma do dicionário para o correspondente"eu"som.

  • 買かう → 買かい
  • 聞きく → 聞きき
  • 話はなす → 話はなし
  • 遊あそぶ → 遊あそび

Grupo 2: Ru-Verbos (Ichidan)

Simplesmente remova o finalる.

  • 食たべる → 食たべ
  • 見みる → 見み
  • 寝ねる → 寝ね

Grupo 3: Verbos Irregulares

Memorize estes dois:

  • する →し
  • 来くる (kuru) →来き(ki)

2. Por que o Caule é importante?

A haste é usada para criar muitas formas comuns. Aqui estão alguns exemplos que você aprenderá:

  • Haste + ます:Forma educada (行いきます)
  • Haste + たい:Expressando desejo (行いきたい)
  • Haste + ながら:Ações simultâneas (歩あるきながら)
  • Haste + すぎる:Fazendo muito (食たべすぎる)
  • Haste + なさい:Dando uma ordem (飲のみなさい)

3. Uso formal

Na escrita formal, o radical pode ser usado sozinho para conectar duas sentenças, assim como oForma Te.
