Até o menor detalhe: ～さえ / ～からして

Quando queremos mostrar que uma situação é tão intensa que até o exemplo mais básico ou inesperado é verdadeiro, usamos `～さえ` ou `～からして`. É como dizer "Mesmo X é verdade, então obviamente o resto também é!"

1. Estrutura da frase

  • `Substantivo` + さえ
  • `Substantivo` + からして

2. Exemplos extremos

  • 子供こども`さえ`知っている。
    (Até uma criança sabe disso.)
  • 彼は自分の名前`さえ`書けない。
    (Ele nem consegue escrever seu próprio nome.)
  • この料理りょうりは、におい`からして`おいしそうだ。
    (A julgar pelo cheiro, este prato parece delicioso.)

3. Nota do Sensei

`～さえ` é usado para "par" geral. `～からして` é especificamente para dizer "a julgar até mesmo por X (que é um pequeno detalhe), a coisa toda deve ser Y." Por exemplo: "A julgar pela atitude dele (`たいど　から　して`), ele é um profissional." Ele destaca um pequeno sinal revelador!
