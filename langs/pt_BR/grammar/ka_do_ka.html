Perguntas indiretas: ～か e ～かどうか

Em japonês, você pode incorporar uma pergunta dentro de uma frase maior para dizer coisas como "Não sei se..." ou "Vou verificar se...". A forma que você usa depende se a pergunta tem uma palavra interrogativa (como "quem" ou "o quê").

1. Perguntas com palavras interrogativas (quem, o quê, onde...)

Use a `forma simples` do verbo/adjetivo seguido de `か`.

  • 何なにを食たべる`か`、決きめていません。
    (Ainda não decidi o que vou comer.)
  • いつ日本にほんへ行いく`か`、教おしえてください。
    (Por favor, diga-me `quando` você irá para o Japão.)

2. Perguntas Sim/Não: ～かどうか

Quando não houver nenhuma palavra interrogativa (por exemplo, "se ou não"), use `～かどうか`.

  • おいしい`かどうか`、わかりません。
    (Não sei se é delicioso ou não.)
  • 明日あした暇ひま`かどうか`、聞きいてみます。
    (Vou tentar perguntar se [ele] está livre ou não amanhã.)

3. Estrutura da frase

Tipo Conexão
Verbos / い-Adj Forma Simples + か / かどうか
な-Adj / Substantivos Substantivo (sem `だ`) + か / かどうか

4. Verbos comuns usados ​​com esta estrutura

Este padrão é quase sempre seguido por verbos de `conhecer`, `verificar` ou `decidir`:

  • わかる (conhecer/compreender)
  • しる (saber)
  • しらべる (para verificar/investigar)
  • きめる (decidir)
  • おぼえる (para lembrar)
