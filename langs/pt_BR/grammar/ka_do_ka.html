Perguntas indiretas: ～か e ～かどうか

Em japonês, você pode incorporar uma pergunta dentro de uma frase maior para dizer coisas como "Não sei se..." ou "Vou verificar se...". A forma que você usa depende se a pergunta tem uma palavra interrogativa (como "quem" ou "o quê").

1. Perguntas com palavras interrogativas (quem, o quê, onde...)

Use oFormulário Simplesdo verbo/adjetivo seguido porか.

  • 何なにを食たべるか、決きめていません。
    (eu ainda não decidio quevou comer.)
  • いつ日本にほんへ行いくか、教おしえてください。
    (Por favor, digaquandovocê irá para o Japão.)

2. Perguntas Sim/Não: ～かどうか

Quando não houver palavra interrogativa (por exemplo, "se ou não"), use～かどうか.

  • おいしいかどうか、わかりません。
    (Não seise ou nãoé delicioso.)
  • 明日あした暇ひまかどうか、聞きいてみます。
    (vou tentar perguntarse ou não[ele] está livre amanhã.)

3. Estrutura da frase

Tipo Conexão
Verbos / い-Adj Forma Simples + か / かどうか
な-Adj / Substantivos Substantivo (nãosim) + か / かどうか

4. Verbos comuns usados ​​com esta estrutura

Este padrão é quase sempre seguido por verbos desabendo, verificando, oudecidindo:

  • わかる (conhecer/compreender)
  • しる (saber)
  • しらべる (para verificar/investigar)
  • きめる (decidir)
  • おぼえる (para lembrar)
