Informações de relatório: ～ということだ

A expressão `～ということだ` é usada para dois propósitos principais: relatar informações ouvidas de outra fonte ("Eu ouvi isso...") ou para explicar o significado de algo ("Isso significa que...").

1. Relatando notícias ou rumores

Quando usado para relatar o que você ouviu, é mais formal do que `～そうだ`. Implica que a informação vem de uma fonte confiável ou é uma declaração definitiva.

  • ニュースによると、明日あしたは大雨おおあめ`ということだ`。
    (De acordo com as notícias, [ouvi dizer que] choverá forte amanhã.)
  • 来月らいげつから物価ぶっかが上あがる`ということだ`。
    (Ouvi dizer que os preços vão subir a partir do próximo mês.)

2. Explicando o significado

Pode ser usado para resumir ou reformular o que alguém disse, ou para definir uma conclusão.

  • 「お金かねはいりません。」
    「つまり、無料むりょう`ということだ`ね。」
    ("Eu não preciso de dinheiro." "Em outras palavras, significa que é grátis, certo?")

3. Estrutura da frase

Anexe `ということだ` à `forma simples` de uma frase.

  • `Verbos/Adjetivos:` Forma simples + ということだ
  • `Substantivos:` Substantivo + だ + ということだ

4. Variações

Na linguagem casual, `ということだ` geralmente se torna `ってことだ`.
