Querendo algo: ～ほしい

O adjetivo `ほしい` (escrito como `欲しい`) é usado para expressar que você deseja um objeto ou que deseja que outra pessoa faça algo por você.

1. Querendo um objeto

Use a partícula `が` para marcar o objeto desejado.

`[Objeto] が ほしいです`

  • 新あたらしい車くるま`がほしい`です。
    (Eu quero um carro novo.)
  • プレゼントは何`がほしい`ですか。
    (O que você quer de presente?)

2. Querer que alguém faça algo

Use a `forma Te` de um verbo seguido por `ほしい`.

`[Verboて形てけい] + ほしい`

  • 一緒いっしょに来き`てほしい`です。
    (Eu quero que você venha comigo.)
  • 日本語にほんごを教おしえ`てほしい`んですが。
    (Gostaria que você me ensinasse japonês [pedido educado].)

3. Conjugação

`ほしい` é um `adjetivo I`.

  • `Negativo:`欲ほしくない (Não quero)
  • `Passado:`欲ほしかった (Procurado)

4. Aviso: egocêntrico

Assim como `～たい`, `ほしい` geralmente é usado apenas para os desejos do próprio falante. Para descrever o que outra pessoa deseja, use `～ほしがっている` (veja o formulário `がる`).
