Adequado para a tarefa: ～向き (むき)

Enquanto~mukeé sobre "intenção",～向きé sobre "adequação". Significa que algo é naturalmente adequado para uma determinada pessoa ou propósito, independentemente de ter sido originalmente projetado para ela ou não. Significa "adequado para" ou "apropriado para".

1. Estrutura da frase

Substantivo+ 向き (だ / に / の + Substantivo)

2. Exemplos apropriados

  • この仕事しごとは彼かれ向きだ。
    (Este trabalho é adequado para ele / Ele é adequado para este trabalho.)
  • この服ふくは夏なつ向きの素材そざいでできている。
    (Esta roupa é feita de material adequado para o verão.)
  • ここは初心者しょしんしゃ向きのコースです。
    (Este é um curso apropriado para iniciantes.)

3. Nota do Sensei

Lembrar:向け= "Eu fiz isso para você."向き= "Isso é perfeito para você." Por exemplo, um “menu infantil” ékodomo-muke, mas uma cadeira pequena e leve pode serkodomo-mukiporque é o tamanho certo para eles!
