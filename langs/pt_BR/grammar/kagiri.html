Contanto que / Dentro dos limites: ～かぎり

A expressão `～かぎり` (escrita como `～限り`) é usada para definir uma condição ou um limite. Isso se traduz como "enquanto...", "enquanto um estado continuar..." ou "na medida de...".

1. Contanto que (Condição)

Use isto para expressar que um determinado resultado continuará enquanto a situação atual permanecer inalterada.

  • 体からだが丈夫じょうぶな`かぎり`、働はたらきつづけたい。
    (`Enquanto` meu corpo estiver saudável, quero continuar trabalhando.)
  • この契約けいやくを守まもる`かぎり`、問題もんだいはありません。
    (`Contanto` que você siga este contrato, não há problemas.)

2. Dentro dos limites de (Extensão)

Use isso para enfatizar que você está fazendo todo o possível ao seu alcance ou conhecimento.

  • 力ちからの`かぎり`、頑張がんばります。
    (Farei o meu melhor “na medida do” meu poder.)
  • 私の知しっている`かぎり`では、かれは犯人はんにんではありません。
    (`Até onde eu sei, ele não é o criminoso.)
