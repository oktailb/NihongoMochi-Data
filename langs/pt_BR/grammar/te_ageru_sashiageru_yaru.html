Dando: あげる, さしあげる e やる

Em japonês, a escolha da palavra certa para “dar” depende inteiramente da relação social entre quem dá e quem recebe. Esses verbos são usados ​​​​quando `você dá para outra pessoa` ou quando `alguém dá para outra pessoa`.

`A Regra de Ouro:` Esses verbos NUNCA são usados ​​quando alguém dá algo `para você`. (Use `くれる` para isso!)

1. Os três níveis de doação

Verbo Polidez Uso
`さしあげる` Honorífico Para um superior (chefe, professor, cliente).
`あげる` Educado/Padrão Para iguais, amigos ou familiares.
`やる` Casual/Descendente Para subordinados, crianças, animais de estimação ou plantas.

2. Exemplos Básicos

  • 私わたしは友達ともだちにプレゼントを`あげました`。
    (Dei um presente ao meu amigo.)
  • 先生せんせいに本ほんを`さしあげました`。
    (Eu [humildemente] dei um livro ao meu professor.)
  • 犬いぬにエサを`やりました`。
    (Eu dei comida para o cachorro.)

3. Fazendo um favor: ～てあげる

Quando você faz uma `ação` como um favor para alguém, use a `forma Te + あげる`.

  • 荷物にもつを持もって`あげます`。
    (Vou carregar suas malas para você.)
  • 友達ともだちに英語えいごを教おしえて`あげました`。
    (Ensinei inglês para meu amigo [como um favor].)

`⚠️ Aviso Pedagógico:` Cuidado! Dizer "～てあげる" para um superior ou até mesmo para um estranho pode soar um pouco paternalista (como se você estivesse apontando que está fazendo um favor a ele). Nesses casos, é mais educado usar `～ましょうか` (Devo...?).

4. Visualizando a direção

Imagine uma seta apontando para longe de você:

`[Doador] は [Receptor] に [Objeto] を あげる。`

O doador é o tópico (は) e o receptor é o alvo (に).
